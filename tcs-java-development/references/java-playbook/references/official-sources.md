# 官方资料索引

检索技术事实时优先使用项目当前版本对应的官方文档。以下链接是方向索引，不代表项目必须升级到这些页面展示的最新版本。

访问日期：2026-09-02。

## WorkBuddy 规范

- [WorkBuddy 专家配置规范](https://open.workbuddy.cn/docs/expert)：目录、`plugin.json`、Agent frontmatter、头像和分类要求。
- [WorkBuddy Skill 规范](https://open.workbuddy.cn/docs/skill)：Skill frontmatter、references、scripts、templates 目录及引用方式。

## Java 与 Spring

- [Oracle Secure Coding Guidelines for Java SE](https://www.oracle.com/java/technologies/javase/seccodeguide.html)：信任边界、输入验证、最小权限、异常、序列化与依赖安全。
- [Spring Boot — Developing with Spring Boot](https://docs.spring.io/spring-boot/reference/using/index.html)：构建系统、代码组织、自动配置和工程建议。
- [Spring Boot — Testing](https://docs.spring.io/spring-boot/reference/testing/index.html)：`@SpringBootTest`、测试切片和测试工具。
- [Spring Security Reference](https://docs.spring.io/spring-security/reference/index.html)：认证、授权、常见攻击防护与测试。
- [JUnit User Guide](https://docs.junit.org/current/user-guide/)：Jupiter 生命周期、参数化测试、扩展和并行执行。

## 构建与质量

- [Apache Maven Introduction to the Build Lifecycle](https://maven.apache.org/guides/introduction/introduction-to-the-lifecycle.html)：生命周期、phase 和 goal 的官方语义。
- [Gradle Java Plugin](https://docs.gradle.org/current/userguide/java_plugin.html)：source set、任务和 Java 项目构建模型。
- [OWASP Java Security Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Java_Security_Cheat_Sheet.html)：Java 注入、XML、反序列化和密码学相关安全建议。
- [OWASP Dependency-Check](https://owasp.org/www-project-dependency-check/)：Java 依赖的已知漏洞检测及 Maven/Gradle 集成。

## 使用要求

- 先确认项目版本，再打开相应版本文档；`current` 或默认页面可能已变化。
- 版本、兼容矩阵、弃用和安全公告属于易变化事实，回答时附直接链接和适用版本。
- 第三方博客只能作为线索；涉及行为、配置和安全结论时回到官方文档或源代码验证。
