# 后期规格与排版模板（锐的工作底稿）

成员卡里写的是纪律，这份是**可直接查的数字与模板**。

## 一、平台图片规格总表

> ⚠️ 平台规则会变。下表用于起步，**交付与上线前必须以平台最新官方规则复核**。

| 平台 | 主图 | 详情页 | 体积/数量 | 备注 |
|---|---|---|---|---|
| 淘宝/天猫 | 800×800（建议 800–1200，支持放大） | 宽 750（部分类目 790） | 单图常见 ≤3MB；主图 5 张 | 主图支持放大镜需 ≥800 |
| 京东 | 800×800 | 宽 790 | ≤3MB | — |
| 拼多多 | 800×800 | 宽 750 | — | — |
| 抖音小店 | 800×800 或 1:1 | 宽 750 | — | 主图视频常见 ≤30s |
| 小红书 | 3:4（1080×1440） | 3:4 | 单图 ≤32MB | 竖版优先 |
| **Amazon** | **建议 2000×2000**（最长边 ≥1600 才启用缩放） | A+ 模块按模板 | 主图 ≤10MB | **主图必须纯白底 RGB(255,255,255)** |
| TikTok Shop | 1:1 | — | — | — |
| Shopee/Lazada | 1:1 建议 1000×1000 | — | ≤2MB 常见 | — |

**Amazon 主图白底的坑**：白底不是「接近白」，是 RGB(255,255,255)。常见翻车是做成 250 灰白或带渐变影，会被拒。

## 二、详情页排版模板（750 宽示例）

```
┌─────────────────────────────┐
│ 首屏 KV｜承接主图承诺        │  ≤800px 高
│ 大字主利益 + 产品全貌        │
├─────────────────────────────┤
│ 模块 1｜Top Benefit ①        │
├─────────────────────────────┤
│ 模块 2｜机制 / 材质 / 工艺    │
├─────────────────────────────┤
│ 模块 3｜使用场景              │
├─────────────────────────────┤
│ 模块 4｜证据（检测/资质/对比） │  有证据才放
├─────────────────────────────┤
│ 模块 5｜规格参数表            │
├─────────────────────────────┤
│ 模块 6｜CTA / 组合推荐        │
└─────────────────────────────┘
```

- **切片**：单张 ≤1500px 高，超出切片；切片位置**避开标题中间**
- **留白**：模块间 40–80px，不贴边连排
- **首屏**：必须承接主图承诺——主图说「一擦即净」，首屏就要看到擦拭效果，不能重新打招呼
- **删减**：按商品删减，不为凑模块硬塞

## 三、切片编号与命名

```
<商品简称>_<平台>_<位置>_<序号>_<宽x高>.<格式>

serum_tmall_hero_01_800x800.jpg
serum_tmall_detail_03_750x1200.jpg
serum_amazon_main_01_2000x2000.jpg
serum_douyin_cover_01_1080x1440.jpg
```

- 序号用两位，保证排序正确（`_01` 而非 `_1`）
- 详情页切片序号即排版顺序，用户不用猜

## 四、字体（商用授权优先）

| 字体 | 授权 |

| 思源黑体 / 思源宋体 | SIL OFL，可商用 |

## 五、文字排版参数（750 宽基准）

| 项 | 数值 |
|---|---|
| 主图标题字号 | ≥ 图宽 3.5%（800 图 ≈ 28px） |
| 详情页正文 | ≥ 图宽 2.5%（750 图 ≈ 19px） |
| 安全边距 | ≥ 图宽 3%（750 图 ≈ 23px） |
| 文字占画面 | ≤25% |
| 行距 | 1.4–1.6 倍 |

## 六、导出检查清单

- [ ] 尺寸与比例符合目标平台
- [ ] 色彩空间 **sRGB**（否则网页端发灰/发艳）
- [ ] 照片类 JPG 质量 85–92；需透明底 PNG；动效 GIF/WebP
- [ ] 单图体积在平台上限内
- [ ] 白底图：Amazon 必须 RGB(255,255,255)
- [ ] 文件命名与编号顺序正确
- [ ] 文字层坐标与内容已记录（便于下游改字）
- [ ] 字体商用授权已确认或已标注

## 七、精修工序顺序（顺序错了会白做）

```
去伪影 → 修边缘 → 校色 → 质感 → 套图统一
```

**先修错再提质**。先调色再修边缘，边缘会留色差边；先锐化再去噪，噪点会被锐化放大。

## 八、常见事故对照

| 事故 | 原因 | 修正 |
|---|---|---|
| 主图有白边/矩形底 | 生成残留，未修边缘 | 阶段 7 修边缘 |
| 移动端文字被切 | 未留安全边 | 内缩到 3% 安全边内 |
| 详情页切片把标题切两半 | 切片位置没看内容 | 按模块边界切片 |
| 网页端图片发灰 | 色彩空间非 sRGB | 导出时转 sRGB |
| Amazon 主图被拒 | 白底不是纯 255 | 重做纯白底 |
| 套图看起来不像一套 | 单张各自调色 | 统一白平衡/对比/锐度 |
| 上架后字看不清 | 字号低于下限 | 按第五节的数值放大 |
