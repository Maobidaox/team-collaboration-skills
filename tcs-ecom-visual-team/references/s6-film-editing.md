# 成片剪辑（阶段 6 后期 / 视频）

蒙太出脚本、雷出素材片段，**成片由剪辑环节装配**。本文管的是电商视频的剪辑节奏与成片规格，不是分镜创意。

> 拿到素材先别急着剪。**先把最强的一帧放到最前面**——电商视频的前 3 秒决定了 80% 的完播。

## 一、三档时长结构（先定档，再剪）

### 15 秒（主图视频 / 抖音 / 信息流）

| 时间 | 内容 | 要点 |
|---|---|---|
| 0–3s | **钩子** | 直接给结果或痛点，不要 Logo 开场、不要空白转场 |
| 3–8s | 产品出现 + 核心卖点 | 产品必须在 3s 内出现，不是 3s 后才出现 |
| 8–12s | 场景 / 证据 | 一个场景足够，不堆 |
| 12–15s | CTA / Logo | 一句话收尾，品牌标识不抢戏 |

### 30 秒（详情视频 / Amazon）

| 时间 | 内容 |
|---|---|
| 0–3s | 钩子 |
| 3–10s | 产品 + 3 个卖点（每点 2–2.5s） |
| 10–20s | 使用场景 + 证据（检测/材质/工艺） |
| 20–27s | 规格 / 对比 / 适配 |
| 27–30s | CTA |

### 60 秒（种草 / 讲解）

在 30s 结构上加：机制讲解（15–25s）、FAQ（40–50s）。**60s 不是把 30s 放慢，是必须有新信息。**

## 二、节奏规则

| 项 | 口径 |
|---|---|
| 单镜时长 | 短视频 2–4s；单个镜头 >5s 必须有运动（运镜或主体动作），否则切掉 |
| 镜头数 | 15s ≈ 5–7 镜；30s ≈ 10–14 镜 |
| 转场 | **硬切为主**。叠化/缩放转场最多用 1–2 次，花哨转场会显得廉价且拖慢节奏 |
| 首帧 | 用最强画面做首帧（也是封面）；不要渐显开场 |
| 尾帧 | 停在产品或 CTA，不黑场 |

## 三、口播稿（要口播时）

- **字数**：语速按 4–5 字/秒，15s 上限约 **60 字**，30s 约 **120 字**。先定字数再写，写完数字数
- **句式**：每句 ≤15 字，口语短句，不写书面长句
- **开头**：第一句就是利益或痛点，不要「大家好，今天给大家介绍…」
- **禁忌**：不出现绝对化用语与功效宣称；口播稿同样要过凌的合规门

## 四、字幕与卖点卡

| 项 | 规则 |
|---|---|
| 字数 | 一屏 ≤15 字，两行封顶 |
| 停留 | 每屏 ≥1s（读不完的字幕等于没写） |
| 位置 | 底部上方 10–15%，避开平台 UI 遮挡区（右侧点赞栏、底部进度条） |
| 卖点卡 | 出现在产品首次展示**之后**，每卡一个卖点，停留 1.5–2.5s，与口播字幕不重叠 |
| 样式 | 高对比（白字+描边/半透明底板），不依赖颜色区分信息 |

## 五、音轨

| 轨 | 电平 | 说明 |
|---|---|---|
| 人声 | -6 ~ -3 dB | 必须最清楚，BGM 让位 |
| BGM | -20 ~ -16 dB | **优先选无人声版**，有歌词会抢人声 |
| 音效 | 点缀即可 | 转场音效每段最多 1 个 |

无人声的纯展示视频：BGM 提到 -14 ~ -10 dB，但起落要平滑。

## 六、导出规格

| 用途 | 尺寸 | 格式 |
|---|---|---|
| 竖版（抖音/TikTok/主图视频） | 1080×1920（9:16） | H.264 MP4 |
| 横版（Amazon/YouTube） | 1920×1080（16:9） | H.264 MP4 |
| 方形（信息流） | 1080×1080（1:1） | H.264 MP4 |
| 封面图 | 与视频首帧一致，单独导出 JPG | — |

- 帧率：25 或 30 fps，**与素材一致**，不混帧率
- 码率：1080p 建议 8–12 Mbps；平台有上限时按上限压
- 体积：常见上限 100–500MB，超了先降码率不降分辨率
- 色彩：sRGB，不过度调色

## 七、平台差异（剪之前先确认投放地）

| 平台 | 要点 |
|---|---|
| 抖音 / TikTok | 前 3 秒决定生死；竖版；字幕几乎必配（多数静音观看） |
| Amazon | 建议 ≤30s；**需同时导出无字幕版与字幕版**；避免夸张承诺 |
| 淘宝/天猫主图视频 | 常见 ≤30s、9:16 或 1:1；体积与时长按类目规则 |
| 小红书 | 竖版；节奏可略慢；封面图单独优化 |

> 平台规格会变，交付时明写：**上线前需以平台最新官方规则复核。**

## 八、剪辑前自检

- [ ] 前 3 秒是钩子吗（不是 Logo、不是空白）
- [ ] 产品在 3 秒内出现了吗
- [ ] 单镜有超过 5 秒不动的吗
- [ ] 字幕读得完吗（每屏 ≥1s）
- [ ] 口播稿字数符合时长上限吗
- [ ] 有绝对化用语或功效宣称吗
- [ ] BGM 有抢人声吗
- [ ] 导出尺寸/帧率/码率符合投放平台吗
- [ ] 首帧单独导出做封面了吗
