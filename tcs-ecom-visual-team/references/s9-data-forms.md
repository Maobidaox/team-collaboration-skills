|--------------|--------|--------|--------|

| 点击量       |        |        |        |
| 点击率 CTR   |        |        |        |
| 访客数       |        |        |        |
| 订单数       |        |        |        |
| 转化率 CVR   |        |        |        |

**先填「同期非视觉变动」再分析。** 不排除这些干扰，后面全是错的。

## 二、漏斗诊断表（按顺序排除，别跳）

| 现象 | 定位 | 处理 |
|---|---|---|
| 曝光低 | 流量/选品/定价 | **不是视觉问题**，如实说明视觉能救的有限 |
| CTR 低、CVR 正常 | 主图不吸引 | 只改主图 |
| CTR 正常、CVR 低 | 详情页没接住 | 只改详情页 |
| CTR 高、CVR 低 | **主图过度承诺**（引流不精准） | 让主图更真实，不是删卖点 |
| CTR 低、CVR 低 | 产品与预期不符或流量不精准 | 查主图是否过度承诺 |
| 都正常但销量低 | 流量规模 | 视觉能救的有限 |

## 五、复盘七问模板

```markdown
## 上线复盘 v{版本}

1. 原定目标：哪个指标、多少？
2. 实际结果：差多少？
3. 差异出在漏斗哪一段？
4. 视觉上最可能的原因（具体到哪张图、哪个模块）？
5. 非视觉干扰因素有哪些？
6. 下一版改**一个**什么？怎么验证改对了？
7. 可复用的经验（写成团队规则）？
```

## 六、改进优先级矩阵

| 影响面 \ 成本 | 低 | 高 |
|---|---|---|
| **高** | 先做（首屏文案、证据位置、模块顺序、主图场景） | 排期做（重拍、整套重新生成） |
| **低** | 顺手做（尺寸、命名、格式） | 不做 |

## 七、纪律三条

1. 不假装有数据 —— 没有就交测试方案
2. 不把相关性当因果 —— 排除同期变动才下结论
3. 不承诺提升 —— 说「大概率改善 X 指标」+ 给验证方法，不说「保证提升 30%」
