# 终审底稿模板（薇的工作底稿）

## 一、四门判定表（复制使用）

```
商品：________  平台：________  版本：v____  终审人：薇  日期：____

门 1 保真      [ ] Pass  [ ] 复核  [ ] Fail
  └ 依据：________________________________________________
门 2 合规      [ ] Pass  [ ] 复核  [ ] Fail
  └ 依据：________________________________________________
门 3 转化      [ ] Pass  [ ] 复核  [ ] Fail
  └ 依据：________________________________________________
门 4 可执行    [ ] Pass  [ ] 复核  [ ] Fail
  └ 依据：________________________________________________

总判定：[ ] 放行  [ ] 有条件放行（附复核项）  [ ] 退回
```

**逐门判定的三条规矩**：
1. 依据栏写**具体是哪张图、哪个问题**，不写「整体尚可」这类空话
2. 任一一门 Fail 就整包不放行，不用其他门的高分抵消
3. 不写百分比分数。用户明确要评分时，给 1–5 分并附依据

## 二、逐槽判定表

| 槽位 | 用途 | 保真 | 合规 | 转化 | 可执行 | 判定 | 处理 |
|---|---|---|---|---|---|---|---|
| hero_01 | 主图 | ✓ | ✓ | 复核 | ✓ | 复核 | 文案占比略高，交用户定 |
| detail_03 | 证据 | ✓ | Fail | — | — | Fail | 检测数据无来源 → 退回凌 |

判定三档：**通过 / 复核 / 不合格**。不合格必须带原因，且原因要能定位到槽位。

## 四、退回单模板

```
退回至：__（环节/角色）
槽位：__（文件编号）
问题：__（一句话，含具体位置）
原因分类：[ 保真 | 合规 | 转化 | 可执行 ]
建议改法：__（可执行动作，不是「再优化一下」）
禁止动作：__（如下游容易顺手做的错事）
```

## 五、快速判定对照（高频问题直接查表）

| 发现 | 判定 | 去向 |
|---|---|---|
| 商品结构/Logo/印花被改 | Fail 保真 | 退回雷，重生成该槽 |
| 色差 Delta E >10 | Fail 保真 | 退回雷，**不自行重生成** |
| 图上有无来源的检测数据 | Fail 合规 | 退回凌，降级或补证 |
| 图内文字与确认稿有出入（含错字） | Fail 合规 | 退回主理人，请用户确认 |
| 两张图讲同一件事 | Fail 转化 | 退回文迪，重排角色 |
| 首屏与主图承诺不衔接 | Fail 转化 | 退回锐，改排版顺序 |
| 尺寸/格式不符合目标平台 | Fail 可执行 | 退回锐，改导出 |
| 文字占比略高但不影响理解 | 复核 | 交用户决定，不阻塞 |
| 审美上不够精致但无硬伤 | 复核 | 交用户决定，**不重生成** |
| 个别槽位失败 | 仅补缺口 | **绝不整批重跑** |

## 六、三条职业纪律提醒

- 不因为「快交了」放行
- 不因为「整体好看」放行
- 不自己动手改（你上手改了，就没人审你了）

## 七、与上游交接

- 从主理人接：全套产出 + 已确认文案 + 证据账本状态 + Style Lock
- 交付给主理人：终审报告 + 退回清单
- 终审通过后，由主理人做交付归档
