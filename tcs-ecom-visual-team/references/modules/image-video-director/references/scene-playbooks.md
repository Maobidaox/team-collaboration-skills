# 赛道配方索引

先按交付主线选一条，**不要把不同赛道的视觉语法混在一支片里**。每个赛道只列其"专属约束"，通用部分见 `prompt-and-consistency.md` 与 `shot-design.md`。

## 快速选路

| 用户要的东西 | 赛道 | 核心风险 |
|---|---|---|
| 商品主图、材质特写、短广告 | 商品视觉 | 气氛图被当成功效证据 |
| 开箱、教程、试穿、口播 | 商品操作 | 步骤状态倒流、手不够用 |
| 穿搭展示、换人换景保商品 | 服饰改编 | 平铺图当首帧、误报单变量归因 |
| 品牌 KV、包装、成套物料 | 品牌视觉 | 标志变形、色值靠猜 |
| 门店/空间短宣传 | 门店纪实 | 生成示意冒充实拍 |
| 软件/网站演示 | 界面证明 | 造出不存在的按钮与数据 |
| 动态字号、音乐包装、追踪风 | 图形编排 | 随机字码当内容 |
| 游戏 PV、角色设定 | 二次元 | 二维风漂成真人、编造玩法 |
| 作品讲解（可双语） | 艺术解读 | 生成笔触冒充原作 |
| 文学/知识讲解动画 | 信息动画 | 史实编造、文字不可控 |
| 真人与二维互动 | 手绘互动 | 贴纸感、接触关系不成立 |
| 儿童睡前故事 | 儿童动画 | 突然响声、结局不安稳 |
| 整曲剧情短片 | 音乐短片 | 靠循环镜头凑时长 |
| 参考某片气质做新片 | 参考转译 | 把猜测写成原片事实 |
| 教学/解说+字幕 | 教育旁白 | 字幕准确性与同步被高估 |

---

## 1. 商品视觉（主图 / 棚拍 / 短广告）

- 先分清**外观展示 / 材质 / 功能 / 品牌氛围**，一个模块只证明一个可见价值
- 棚拍未指定数量时默认四张：干净主视觉、材质微距、生活方式、留白广告款
- 转场从形状、材质、液体、前景遮挡或动作承接出发，明确"前镜结束→后镜开始"
- 缺真实结构依据时**不生成伪内部剖面**；透明材质、反射、持握是高风险位，优先局部重修
- 验收顺序：商品可辨 → 卖点是否被画面支持 → 节奏与落幅

## 2. 商品操作（开箱 / 教程 / 试穿 / 口播）

- **先辨产品机制**：按压泵、旋盖罐、喷雾、滴管、电子设备的动作次序完全不同；看不清就请用户说明，不用通用"护肤动作"顶替
- 逐步状态表：封口/盖子、剩余量、干湿或混合状态、位置、握持手、可见面；下一步从上一行继续
- 开箱顺序：未拆包装 → 拆封 → 首次完整揭晓 → 细节；揭晓前只给合理局部
- 无外箱素材时只能建议中性运输包装，**不伪造品牌包装**
- 介绍只讲一个购买理由；教程必须证明"用户能跟做"；开箱围绕揭晓；试穿讲服装与人的关系——不要把所有请求都写成面对镜头口播

## 3. 服饰展示与受控改编

- 三类参考分开：衣物平铺（约束部件）、住宅（约束空间光向）、人物全身与脸（约束身份）
- 平铺衣物要先得到**穿着构图**再动起来；普通参考合成只能叫"穿搭概念"，不称真实尺码试穿
- 五秒低动作方案：静立 → 轻移重心 → 短暂落幅；不要同时叠转圈、走路、拉衣、绕拍
- 换人+换装+换景是**一组创意变化**，不包装成单变量归因实验
- 无视频编辑能力时可提议"按相同结构重制"，不称原片精准替换；原片读不到就不编动作轨迹

## 4. 品牌视觉系统

- 规则先于出图：标志原件、品牌色及用途、字体来源与语言覆盖、版式层级、留白、图形母题、准确文案、目标尺寸
- 画面"看起来像"不等于量得准色值或识别出字体文件；以官方规范与用户书面确认为准
- 新视觉方向必须落到一个具体形状、负空间、工艺或色彩关系，不用"高级、现代"当方案
- 用户没要求重做标志时**不插入标志设计流程**；只做配色就别顺带做整套品牌
- 成套并排检查标志、色用、文字、间距、图形与例外；色值/字体/标志规则留在项目记录里，不指望主体 ID 保存规范

## 5. 门店与空间纪实

- 主线："到达 → 准备 → 服务 → 离开后的感受/品牌落幅"，每段只选**素材能支撑**的真实动作
- 只有空间照片时，把服务段列为待补拍，先编排已有照片；不捏造服务设施
- 景别逻辑：整体定位 → 中景交代人与工作区 → 近景解释前一镜的动作 → 可辨识收尾
- 真实感来自动作先后合理、手与工具接触成立、窗光方向一致、环境声不断裂
- 横版强调空间两端关系；竖版重新安排脸、手、工具位置。**只有横版完成不能报横竖全成**

## 6. 界面演示与功能证明

- 软件宣传 ≠ 操作教程：前者强调一条价值路径，后者必须能让人照做
- 五拍因果：初始状态 → 产品展开 → 一次明确操作 → 可验证结果 → 品牌收束
- 全段只用一种主要交互来源（光标或触摸）；每个状态变化由**可见操作**触发，不能点了左边右边无因弹出
- 不生成不存在的按钮、数据、页面；只有概念界面时明确标"概念"
- 界面小字优先真实录屏或可控排版；生成画面让小字变形时不能标"准确教程"
- 验收：静音看操作是否造成正确变化；纯听旁白能否指向同一步

## 7. 动态文字与图形编排

- 文字只担一个职责（主标题 / 次信息 / 准确标签），图形负责承载与连接；一段只留一个最强运动焦点
- 生命周期写全：触发 → 进入 → 完整可读 → 反应 → 退场；**先让字能读，再裁切变形**
- 追踪风可用局部空心框、连接线、受控窗口，但明说这是艺术效果，**不称检测框或测量坐标**
- 精确字幕、无损叠层、可编辑工程需要真实后期能力，不能与"生成式包装"互相冒充
- 参考改编时区分"视频观察 / 静帧观察 / 用户陈述 / 推断"，再列保留项与修改项

## 8. 二次元宣传与角色

- 角色图固定脸、发型、服装、武器、人数与**二维媒介**；版式图只给图文层级，不带入别人角色与文案
- 一条主线，例如"细节—剪影—全貌—定版"或"平静—触发—变化—稳定新状态"
- 转场要有可见承接；特效表现触发与结果，不靠连续闪光替代动作
- 卡牌层移动、二维遮罩不是人体动作，不能塞进动作库
- 验收：二维风未漂成真人、角色与武器不变、转场有方向、结尾可读；**玩法机制只能来自资料**

## 9. 艺术解读（可双语）

- 必须有真实作品图与可核查资料；无原图**不生成相似画冒充原作**
- 观看路径："整体定位 → 局部细读 → 局部关系 → 回到整体"；旁白讲哪里，画面就指向哪里
- 引用细节用真实裁切、可控推近或标注，不用生成笔触当证据
- 双语不是"换字幕"：两版共享事实，各自口语写作，保留同一断言的限定词，各自实测时长与切点
- 片长严格相同时先调措辞与停顿，不硬拉伸语音

## 10. 文学旅途与信息动画

- 每段写"目标—阻碍—行动—结果"，砍掉不影响因果的支线；**一个地点不必一个镜头**
- 换地点先用全景或明确场景标志定位，再拍人物行动；地图标明文学示意，不伪装精确航线
- 三条视觉路线不混用：黏土（压痕、哑光、微缩布景）、线条人物（稳定线宽、简化表情）、编辑图形（日期、时间轴、箭头承载信息）
- 旁白讲原因，画面演结果或出示证据，不把同一句话写满屏
- 动态文字与准确图表需可控绘制/排版能力，否则交图形说明 + 旁白素材

## 11. 手绘互动与连续变形

- 核心是**人与手绘对象有因果关系**：人推动 → 对象反馈 → 相机跟随；不是给画面贴漂浮贴纸
- 每次变化记录：起始形态 → 触发动作 → 中间形态 → 最终形态 → 保留的颜色与轨迹
- 手绘实体要有透视、遮挡、接触、投影：进杯被壁挡、落地有落点
- 保留手机质感（轻手抖、追拍滞后、对焦犹豫、曝光波动），但力度要服务接触可读性
- 默认无 BGM、无旁白对白，保留环境声与物体声；用户另加音乐要记为"配方变更"

## 12. 儿童动画（毛绒 / 睡前）

- 固定脸型、发色、帽形、花朵位置、衣服比例与毛绒方向；身份不变量与场景色调分开
- 结构：发现小问题 → 一次尝试 → 得到帮助 → **安稳解决**；用动作解释，不靠旁白补漏洞
- 一镜一个动作（看见、伸手、轻放、靠近、闭眼），为眨眼与反应留短停顿；相邻镜保持物件在哪只手、灯是否已关
- 大块清晰轮廓 + 柔和接触阴影 + 可辨材质；避免所有物体都变成同一种毛球
- 声音温柔、音乐低强度持续、结尾随动作渐缓；**不因片长到点硬切音轨**

## 13. 音乐短片（整曲 / 双人）

- 先定位既有角色资产并绑定 A/B；发型、脸、服装、随剧情变化的道具分列
- 先拿到完整连续音轨并实测语言、长度、段落，再写音乐时间表；无音频分析能力时只把用户段落说明当依据
- 用"起始关系 → 分离/误会 → 互相寻找 → 关系改变"串起整曲；每段写明"这次与上一镜相比改变了什么"
- 音乐表列：起止、歌词语义、能量、A 状态、B 状态、共享物件、镜头目的
- 不循环相同镜头凑时长；没有整曲或合成能力时交时间表 + 已成功镜头，不称完整作品

## 14. 参考转译（借某片的气质做新片）

- 分别记录空间层级、光色、尺度参照、主体揭示顺序、相机运动、单镜长度、音乐段落；每条注明观察依据
- **只有缩略图时只分析构图，不分析运动节奏**
- 提取结构而非堆关键词：如"前景遮挡—中景主体—远景天际"建立深度，细小重复物提供尺度参照
- 动态提示按"固定建筑关系 → 相机路径 → 背景相对速度 → 起止构图"编译，用前后景不同移动量做视差
- 没有原曲或音频能力时保留节奏方案，不声称已复制同曲

## 15. 教育旁白与字幕

- 学习目标决定镜头：让观众能**解释、比较或完成一个动作**，再排先备知识、概念、例子/反例、简短检查
- 固定窗口旁白：按实际时长估算能自然说完的内容，先保事实与必要动作，再删赘词
- 声音来源要讲清：参考音频 ≠ 主体可选声音 ≠ 独立配音 ≠ 克隆音色 ID；没有接口不自编声音 ID
- 字幕稿 / 可切换字幕 / 烧录字幕 / 动态标题是四种交付物，别混称
- 验收：旁白可懂、原声是否保留、字幕拼写与句界与安全区；**文稿正确不等于画面排版正确**
