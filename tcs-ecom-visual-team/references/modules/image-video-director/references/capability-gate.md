# 生成能力门与参数封闭

本文件只管"能不能调、怎么调"；创意方法见 `prompt-and-consistency.md`。**任何工具名、模型名、参数、枚举都以本轮宿主真实 schema 为准，本文任何名称都不是白名单。**

## 一、能力发现顺序

1. 确认宿主**当前真实暴露**了图像/视频生成能力（连接器已连接、工具在清单里）
2. 取一次运行时自检信息（连接状态、可用工具、规范模型名、账号限制），以它返回为准
3. 若返回"工具清单已更新"类提示 → 停止提交，要求重连或重启宿主，刷新后重新发现
4. 记录：工具名、模型名、参数白名单、输入槽位、必填项、默认值、允许值、时长/画幅限制
5. 公开网页能力、历史日志、其他 Skill 的示例**不能覆盖**当前合同

未连接时的正确做法：暂停媒体执行，引导用户到连接器/插件面板完成授权，回来后继续原任务。**不得索取 API Key / Token / Cookie，不得改用其他生成服务兜底。**

## 二、业务能力 → 意图映射（不含具体工具名）

| 你要做的事 | 需要的能力 | 关键限制 |
|---|---|---|
| 纯文字出图 | 文生图 | 无图片输入；不传模型未声明的字段 |
| 在已有图上改 | 图生图 | 输入槽位随模型变化，逐项读 schema |
| 纯文字出视频 | 文生视频 | 时长、画幅、音频、多镜字段只在声明时传 |
| 用图出视频 | 图生视频 | 首帧/尾帧/多参考图是不同模型合同 |
| 用动作驱动人物 | 动作控制 | 动作源 ≠ 视频编辑能力 |
| 上传参考素材 | 素材上传 | 用返回的不透明引用；本地路径不得冒充生成输入 |
| 查任务进度 | 任务查询 | 用原任务号；查询**不得**创建新任务 |
| 查余额/成本 | 账户查询 | 连接器没给价格就说未知，不估算扣费 |
| 复用人物/商品 | 主体资产 | 与动作资产分离；模型不支持时不得硬塞 |
| 复用动作 | 动作库 | 不虚构动作 ID；无预览不称适配 |

## 三、参数封闭七条

1. 先定工具和规范模型，再从当次 schema 建参数白名单
2. **换模型就废弃已构造字段**，重新建立；不同模型字段不可混用
3. 必填且无默认值的字段必须能从用户意图或素材得到，得不到就问或停
4. 可选无默认值的字段只在任务需要时传；不传空串、null、空数组、猜测值
5. 枚举用当次 `allowedValues` 的精确字符串；账号等级可能缩小范围
6. 输入槽位用所选模型实际声明的名字；首帧与尾帧槽位**不可互换**，不可用历史别名
7. 画幅、分辨率、时长、音频、多镜、主体、参考音频——只在声明时传

## 四、能力缺失怎么写（不要含糊）

| 缺失的能力 | 正确交付 |
|---|---|
| 无生成式视频编辑 | 局部替换/重绘标记 `unsupported`；可提议"按相同结构重制"，但**不称精准替换** |
| 无独立 TTS / 音效 / 音色克隆 | 交出用户音轨方案与配音稿；参考音频字段 ≠ 声音库 ≠ 克隆 |
| 无精确文字渲染 | 提示词写"no text, leave negative space"，文字后期叠加 |
| 无逐帧跟踪 | 可做艺术性框选效果，但**不称检测框/测量坐标** |
| 无整曲生成与合成 | 交时间表 + 已成功镜头，不称完整音乐作品 |
| 只能读封面图 | 不做拉片、不编造动作节奏与切点 |

统一记法：`unsupported` + 阻塞原因 + 已完成的上游产物 + 最小可继续步骤。

## 五、提交与结果

- 每个确认版本一个**唯一提交键**（`workflow-id:artifact-id:version`），只提交一次
- 提交后立刻登记真实任务号与状态；宿主原生结果组件负责展示，不要自造展示工具
- 超时、等待、刷新、状态查询**都不构成重发理由**；先用原任务号恢复
- 任务 READY 只证明产物可取，不等于视觉/听觉验收通过
- 重试必须建立新的提交键 + 新的用户授权回执；旧确认不能自动触发扣费
- 素材临时链接要记有效期；交付前保存稳定副本或明确提醒下载期限

## 六、三个 "不要"

- 不要因为没有生成能力就宣称"做不到"——方案档照样能交付
- 不要用"任务已受理""已提交""生成中"包装成"已完成"
- 不要输出 Token、授权头、内部服务 ID 或连接器原始响应
