# 镜头设计与衔接

出视频和出图的差别，全在"这一镜改了什么"。本文件管第④步：把脚本翻译成可生成、可衔接、可验收的镜头。

## 一、单镜四要素

每个镜头必须写全这四项，缺一项就会生成"好看的废片"：

1. **主体动作**：谁做什么，一个镜头只做一个主要动作
2. **运镜**：固定 / 慢推 / 侧移 / 跟随 / 升降；幅度与方向明写
3. **时长与节奏**：几秒、快慢、是否留停顿
4. **首帧状态 → 尾帧状态**：物件在谁手里、谁已躺下、灯是否已关

## 二、镜头衔接的唯一规则

> **上一镜的末状态，就是下一镜的输入。**

写作时逐镜记录"这次见面与上一镜相比改变了什么"。同一个动作反复摆拍、无因跳切、变形到一半换形态，都算衔接断裂。

转场必须有**可见承接**：物件从哪进入、遮住了什么、下一状态如何出现。特效表现触发与结果，不靠连续闪光替代动作。

## 三、节拍密度（别按秒均分）

| 内容类型 | 结构 |
|---|---|
| 商品 / 品牌短片 | 2–4 个视觉模块，3–6 个**不均匀**节拍；主视觉 → 材质微距 → 功能操作 → 场景尺度 → 清晰落幅 |
| 产品介绍口播（10 秒） | 0–2s 情境带出，2–7s 稳定持瓶/持物介绍，7–10s 落幅并说完名称 |
| 门店 / 空间纪实（30 秒） | 约 5s 空间、8s 准备、10s 核心服务、7s 落幅（依素材调整） |
| 软件演示 | 初始状态 → 产品展开 → 一次明确操作 → 可验证结果 → 品牌收束 |
| 教育讲解 | 先备知识 → 概念 → 例子/反例 → 简短检查 |
| 儿童故事 | 发现小问题 → 一次尝试 → 得到帮助 → 安稳解决 |

以上是**设计建议**，不是原片实测；有真实参考片或真实音频时按实测调整。

## 四、动作合理性检查（最容易翻车）

- **手不够用**：自拍时一只手已握手机，即使不在画内也不能再用来开盖；要两手就改固定机位
- **一个节拍一个动作**：开盖、挤出、涂抹、盖回不能压在同一秒——先缩台词，不是硬塞动作
- **状态不能倒流**：已拆封的包装不能自己封好，挤出的内容物不能消失又补满，商品不能无理由多一件
- **握持避开文字**：手指不遮标签，瓶口/手指/嘴部不要同一时刻复杂交互
- **接触成立**：脚落地、手与工具接触、进入容器后被壁面遮挡、落地有明确落点

## 五、内容真实性红线

- 生成战斗画面 ≠ 可玩游戏功能；概念界面 ≠ 已上线产品；生成示意 ≠ 门店实拍
- 玩法、机制、成分、功效、史实只能来自资料；没有依据不补充
- 神话不做考古证据，示意地图不伪装精确航线
- 商品测评式演绎只能说已证实信息，不虚构"真实买家体验"

## 六、声音与字幕的排布

- 一条主线只有一个主叙事声：人物同步口播 **或** 画外旁白，二选一
- 背景乐在人声处让位；商品动作音/环境声只在对应该动作时出现
- 不要为每个推近都加转场音效；"无此音效"优于无意义铺满
- 结尾让动作与声音一起渐缓，不因片长到点硬切音轨
- 没有真实音频文件时，所有时间标注为**预计**，不写"已实测同步"

## 七、提交前逐镜自检

- [ ] 每镜一个主要动作，主体、运镜、时长、首末状态四要素齐
- [ ] 上下镜末状态能接上（谁拿物、朝向、位置）
- [ ] 动作符合产品机制，手够用，状态不倒流
- [ ] 画幅内主体不被裁断（横竖版分别验）
- [ ] 台词只留一个信息点，能在一镜时长内自然说完
