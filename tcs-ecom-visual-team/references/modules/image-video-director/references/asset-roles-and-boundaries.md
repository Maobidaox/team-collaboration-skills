# 素材角色与修改边界

素材理解错了，后面所有提示词都是白费。本文件负责第②步：把附件翻译成"角色 + 边界 + 冲突裁决"。

## 一、素材角色判定顺序

1. **用户在文字里怎么说的**优先于你的猜测（"这是参考风格""按这张的脸做"）
2. 文字没说的，按**画面内容**判：全身/局部写真人像 → 主体参考；纯光色质感 → 风格参考；有空间关系 → 场景参考
3. 仍然判不出，**问一句**，不要两种用法都试一遍

禁止的默认推断：

- 附了图就当首帧
- 附了视频就当动作源
- 多视图拼图当多个角度（拼图里其实是同一张复制多次）
- 平铺衣物图当"已穿好"的首帧
- 竞品/参考片里的人脸和服装跟着一起迁移

## 二、三栏边界表（每个任务必写）

| 栏位 | 内容 | 例子 |
|---|---|---|
| 必须保持 | 不可变项 | 人物五官与发型、商品包装轮廓与标签、品牌标志比例、容器开口位置、画面文案 |
| 允许改变 | 本次要变的部分 | 背景、光线时段、服装、机位、动作、时长 |
| 禁止出现 | 负向清单 | 畸形手、多余肢体、水印、伪文字、竞品 Logo、未授权人物、错误规格 |

**一次只改一个变量**。改光影就不同时改构图；做 A/B 归因才需要锁定其他因素、只动一项。若用户其实要的是一组创意变化（换人+换景+换装），不要包装成"单变量实验"。

## 三、素材冲突裁决

常见冲突与处理：

| 冲突 | 处理 |
|---|---|
| 图里标签文字与用户要的版本不符（如蓝莓瓶要做芒果版） | **保留冲突并请用户裁决**；不得擅自改标签凑需求，也不得默认按图中文字走 |
| 只有一味参考，用户要三味 | 说明只有一味包装素材；可先推进不依赖包装的场景与口播结构 |
| 参考图色差/近似品牌色 | 不等于量得准确色值；色值与字体以官方文件或用户书面确认为准 |
| 用户要"印刷母版" | 无刀模/出血/印刷配置时不称母版，只交效果图与文字规范 |
| 用户要"可编辑矢量标志" | 栅格标志不称矢量原件；标志持续变形时交完整原标志 + 后期要求 |

## 四、授权与身份红线

- 真人身份、商品结构、品牌资产：**未经授权不得改造**。用户说是自己的素材，也要确认可商用范围
- 公众人物、第三方影视/游戏素材、竞品商品：不主动生成"替换/仿冒"版本
- 儿童相关：不做恐怖、危险模仿、不当身体暴露
- 文博/艺术作品：无原作原图时**不生成相似画冒充原作**，只交构图分析或授权素材方案

## 五、素材质量预检（省一次付费生成）

出图/出片前先看素材本身够不够撑：

- 主体参考：脸是否清晰、有无遮挡、分辨率是否够放大
- 商品参考：标签是否可读、包装是否有多个面、反光是否吃掉结构
- 场景参考：光向是否一致、地平线是否明确、有无会穿模的家具边缘
- 视频参考：能否完整读取动作与时长；只有封面图时**不分析运动节奏**

预检不通过 → 请用户补素材（正/侧/背、细节、包装多面），不要用一张图硬撑完整套图。

## 六、素材登记表（交付时给用户看）

```
| 编号 | 文件 | 角色 | 定义了什么 | 不用于 |
| A | person_front.jpg | 主体参考 | 脸、发型、体型 | 不做场景参考 |
| B | flat-lay.jpg | 衣物参考 | 上衣/下装/鞋/包 | 不是穿着首帧 |
| C | room.jpg | 场景参考 | 光向、家具、地面 | 不带入原图人物 |
```
