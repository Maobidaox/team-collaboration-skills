# Storyboard 与图内文案

> 原专家只说「不要固定 5 张」，不给规则。这份补上**张数怎么定、每张写什么、文字放多少**。

## 1. 张数决策：数「疑问」，不数「卖点」

### 定张数三步

1. **列出买家的购买疑问**（从评价、客服问题、竞品详情页反推），例：
   - 这是什么？跟别家有什么区别？
   - 值这个价吗？凭什么？
   - 我的情况下能用吗？（尺寸/适配/口味）
   - 到手是什么样？够不够用？
2. **一个疑问 = 一张图**。合并两个疑问的图，两个都答不好。
3. **能被文字参数替代的疑问，不必单独出图**——放进 Spec 图解决。

### 参考张数

| 张数 | 适用 | 说明 |
|---|---|---|
| 3 | 单一 SKU、单规格、低客单冲动品、TikTok / 拼多多首屏 | 识别 + 一个理由 + 规格/价格 |
| 5 | 标准电商上架（淘宝/天猫/京东常规） | 识别 → 利益 → 证据 → 场景 → 规格 |
| 7–9 | 多规格/多口味、重证据品类（食品、母婴、保健、高客单）、Amazon 等货架型平台 | 每个选择维度、每条必须证明的宣称各 +1 |

**不要为了「显得丰富」加图**。一张答不出独有疑问的图，会稀释前面几张的注意力。

## 2. 角色卡：每张图写什么

### KV1 · Hero（识别 + 单一核心理由）

- **视觉任务**：3 秒内让买家认出「这是什么、什么牌子、大概什么档次」
- **画面**：主体占 55–65%，正面或 3/4 微俯视，干净背景，无多余道具
- **文案**：1 个标题即可，不超过 12 字
- **常见错误**：把 5 个卖点全塞首图；主体只占 30% 导致缩略图看不清

### KV2 · Benefit（参数 → 收益）

- **视觉任务**：把最重要的 1 个参数翻译成「对我有什么用」
- **画面**：对比式构图（左问题/右解决）或放大特写 + 局部标注
- **文案**：标题给收益，副文案给参数支撑
- **常见错误**：只放参数不放收益（「20kg 承重」vs「20kg 承重，整箱饮料放得下」）

### KV3 · Proof（证据）

- **视觉任务**：回答「凭什么信你」
- **画面**：产地/工厂/检测报告/工艺特写/资质原件（**真实可查的**）
- **文案**：标注来源，如「SGS 检测 SH2024-0815」
- **常见错误**：画一个假的「认证徽章」——**这属于硬阻断项，不能让模型生成**

### KV4 · Scene（场景代入）

- **视觉任务**：让买家看到「在我的生活里长什么样」
- **画面**：真实使用场景，人物可入镜但手部/比例要真实
- **文案**：可留空（纯视觉图），或一句场景短句
- **常见错误**：场景过度精致反而失真；产品或比例在场景里不对

### KV5 · Compare（客观对比）

- **视觉任务**：降低选择成本，让买家自己得出结论
- **画面**：本品不同规格对比，或本品与「常见选择维度」对位（**不虚构竞品数据、不用贬损表达**）
- **文案**：只写可核验的维度与数值
- **常见错误**：编造竞品参数；用「普通款」暗示贬损

### KV6 · Spec / CTA（规格与下一步）

- **视觉任务**：消除最后的购买障碍（够不够用、怎么选、含什么）
- **画面**：规格表、尺寸图、套装清单、适配关系图
- **文案**：数字必须可读，单位必须标
- **常见错误**：参数抄说明书不做图示；尺寸不标单位

## 3. 详情页模块（按商品删减，不为凑数硬塞）

| 顺序 | 模块 | 叙事功能 | 可删条件 |
|---|---|---|---|
| M1 | 承接首屏 | 复述主图核心价值，防止跳出 | 不可删 |
| M2 | Top Benefits | 3 条核心购买理由 | 不可删 |
| M3 | 机制/材质/工艺 | 解释「为什么有效」 | 纯外观型商品可压缩 |
| M4 | 场景 | 代入真实使用 | 不可删 |
| M5 | 证据 | 产地/检测/资质/供应链 | 无可信证据时**改为中性表达，不要编** |
| M6 | 对比/选择 | 规格、型号、口味横向对比 | 单一 SKU 可删 |
| M7 | FAQ | 配送、使用、售后、顾虑 | 有高频客服问题就必须留 |
| M8 | 规格 + CTA | 参数表与下一步 | 不可删 |

## 4. 图内文案密度（移动端可读性）

> 以下是**通用排版经验值**，不是平台规定。平台对主图加字的具体限制必须核验官方最新规则。

| 位置 | 建议上限 |
|---|---|
| 主图标题 | 中文 ≤ 12 字；英文 ≤ 6 词 |
| 主图副文案 | ≤ 1 行 |
| 详情页模块标题 | 中文 ≤ 20 字 |
| 详情页正文 | 每段 ≤ 3 行 |
| 单张图文字总面积 | ≤ 画面 20%（主图） |
| 单行长度 | ≤ 14 个汉字（375px 宽手机屏） |

### 三条硬规则

1. **数字必须比同级文字大 1.4–1.8 倍**——买家先看数字。
2. **一行只表达一件事**。出现「并且」「还有」「同时」就拆行。
3. **文字必须有承载区**。文字直接压在产品或复杂背景上会糊，先给色块/渐变/留白底。

### 文案写法对照

| 别写 | 改写成 | 为什么 |
|---|---|---|
| 专业品质，值得信赖 | 304 不锈钢内胆，不锈不串味 | 前者无信息量，后者可验证 |
| 超大容量 | 20L，装得下 24 听可乐 | 抽象形容词换成可感知度量 |
| 匠心工艺，精益求精 | 手工打磨 6 道，边角无毛刺 | 「匠心」是自评，工序是事实 |
| 全网最低价 | （删除或改为真实活动价与条件） | 无法证明的比较属于高风险 |
| 改善睡眠，一贴见效 | （高风险功效，改中性：描述材质与使用方式） | 普通商品不得宣称功效 |

## 5. 交付前自检

- [ ] 每张图能否一句话说出「它回答哪个疑问」
- [ ] 有没有两张图回答同一个疑问
- [ ] 有没有哪张图的疑问其实用文字参数就能解决
- [ ] 首图在缩略图尺寸（约 200px 宽）下还能认出产品吗
- [ ] 所有数字都有单位
- [ ] 图内文案总数是否超密度上限
- [ ] 每张图的证据是否已在账本中且状态可用
