# 反 AI 感与合规

## 一、为什么"越精致越假"

AI 出图的默认审美是**过度完美**：皮肤无毛孔、光比平均、构图准得像摆拍、背景干净得没有人住过。电商 UGC / 直播 / 社媒要的恰恰相反——**可信度来自不完美**。

五套模板内置了 `anti_ai_tips`（`detail-macro`、`social-media`、`ugc-style`、`model-showcase`、`livestream`、`magazine-editorial`），其余场景不需要重手反 AI，但也别往"完美"方向写。

## 二、反 AI 七条（UGC / 直播 / 社媒强制）

1. **指定机型**：`iPhone 14 Pro`、`iPhone 15 Pro`，或 `2005 CCD digicam` 走复古路线
2. **写可见瑕疵**：毛孔、可见噪点、轻微偏黄、构图歪、焦点略软
3. **真实环境**：台面有水渍、毛巾用过、床上被子是皱的、背景有杂物
4. **明写否定句**：`NOT professional photography`、`NOT AI-generated look`、`NOT retouched, NOT smoothed`、`NOT studio quality`
5. **胶片色调**：`Kodak Portra 400 color feel`（或直接写黄绿偏色 + 高光溢出）
6. **构图不完美**：off-center、slightly tilted、产品标签不全在画面正中
7. **禁用 AI 签名词**：`perfect`、`flawless`、`stunning`、`hyper-realistic`、`8K ultra detailed`（UGC 场景尤其）

## 三、三个场景的具体写法

**UGC 买家秀**
> 浴室镜自拍，iPhone 前摄，镜面有轻微水汽，暖黄室内光。人物手持产品，标签可辨认但没居中。皮肤可见毛孔与轻微泛红，NOT flawless。整体偏黄、有手机噪点、姿态自然不摆拍，NOT AI-generated look。

**直播间**
> 手机竖屏直播截图，主播半身，身后货架有真实杂货与打光板，桌面有产品和零散包装。屏幕上有评论浮层与在线人数（文字后期加）。轻微过曝、噪点、实时流媒体画质。

**社媒帖（小红书 / IG）**
> 平视手机随拍，产品放在真实生活的桌面，旁边有半杯水和耳机。自然窗光 + 室内灯混色，色调偏暖，轻微暗角。构图随意，NOT styled。

## 四、文字类场景（海报 / 信息图 / A+ / 尺寸规格 / 多角度网格）

AI 生图对文字还原**有限且不稳定**，长串文字必出错字、乱码、错拼。

规则：

- prompt 里只写"留出标题区"，具体文案让模型别画
- 若要模型带字，只允许 1–3 个短词，且交付时必须提醒"逐字核对"
- **关键文案（价格、规格、认证、成分、促销信息）一律后期叠加**
- 版式类需求（A+ 多模块）建议：先生成空版式与产品图，再用设计工具填字

## 五、合规红线

| 风险类型 | 具体表现 | 处理 |
|---|---|---|
| 医疗/功效 | "治疗""修复受损屏障""7 天祛斑" | 改写为可证实的感官描述；不帮绕过 |
| 绝对化 | 最、第一、顶级、永久、100% | 改为"高""持久"等可承受表述，或建议删 |
| 前后对比 | 暗示疗效、夸张落差 | 只做可见变化（清洁度、使用痕迹），不加疗效承诺 |
| 食品 | 暗示保健/减肥功效 | 只讲口感、配料、场景 |
| 资质与数据 | 让模型"画"认证徽章、检测报告、销量数字 | **禁止生成**，一律后期用真实素材合成 |
| 他人资产 | 竞品 Logo、明星肖像、影视 IP | 不让模型生成 |

## 六、交付时必须说的三句

1. prompt 是给生图工具用的，图要自己去生成
2. 有产品白底图就一起上传参考，一致性会明显更好
3. 含文字的场景：AI 还原文字不可靠，关键文案后期叠
