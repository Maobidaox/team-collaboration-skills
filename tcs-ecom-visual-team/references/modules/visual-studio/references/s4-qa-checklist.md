# 阶段④-B：成片质检清单（伊万 / Evan）

用户把提示词喂给生图工具、拿回图片后，按此清单**逐槽验收**。

## 输出 `outputs/05-qa-checklist.md`

## 四个验收维度

### 1. 商品保真（任一不可变结构变化即不合格）

- [ ] 形状
- [ ] 结构
- [ ] Logo
- [ ] 印花文字
- [ ] 主体色

### 2. 商业呈现

- [ ] 无抠图感
- [ ] 无白边 / 矩形底
- [ ] 无文字错误
- [ ] 应有文案齐全且**逐字正确**
- [ ] 无关键遮挡
- [ ] 无未确认文字
- [ ] 无水印或多余说明栏

### 3. 套图连续性

- [ ] 同款商品跨图一致
- [ ] 场景族与多样性符合方案
- [ ] 无重复模板

### 4. 色差（有条件时实测）

用取色工具测 **Delta E**：

| Delta E | 判定 | 动作 |
|---------|------|------|
| ≤3 | 通过 | — |
| 3–5 | 轻微提示 | — |
| >5 | 警告 | — |
| >10 | 不合格 | 用**同一锚图**、**简化背景**，最多**重试 1 次** |

## 判定口径（重要）

- 逐槽给出：**通过 / 复核 / 不合格 + 原因**
- **只有关键结构漂移才重生成该槽**
- 文字或审美的小问题：**保留原图并标记复核**，不重生成
- **绝不要求整批重跑**

## 交付话术

验收时在对话中给出：每槽判定 → 需要处理的清单（哪几槽要重生成、哪几槽仅标记复核）→ 重生成的具体做法（换哪张锚图、简化什么）。
