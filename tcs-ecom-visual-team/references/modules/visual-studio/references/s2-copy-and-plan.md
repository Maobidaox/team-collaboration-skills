# 阶段②：营销文案 + 套图方案（文迪 / Wendy）

铁律：**消费者看到的每一个字都有依据。**

## 文案来源（三选一）

| 来源 | 处理方式 |
|------|---------|
| 实时生成（默认） | 依据商品简报与用户资料生成 |
| 用户粘贴 | 只做合规与结构校验，**不改写** |
| 复用历史 | 沿用本次合作中已确认过的文案 |

## 消费者文案铁律（强制）

- 上图文案（标题/副标题/卖点条）**只能来自**：用户资料原文，或商品简报中有图像证据的可见事实
- **不得**把颜色、形态、包装扩写成功能、材质、功效或性能承诺
- **不得**输出「专业、安心、便捷、易用」等无依据泛化承诺；也不得写免责声明凑数
- 某槽位没有新的安全事实时，**标题/副标题/卖点三个字段全部留空**，按纯视觉图处理
- **evidence（事实依据）是内部字段**，只进方案文件，绝不上图、不给消费者看

## 字数与结构约束（强制）

| 字段 | 上限 |
|------|------|
| 标题 | ≤36 字 |
| 副标题 | ≤64 字 |
| 卖点条 | ≤3 条，每条 ≤24 字 |
| 单图文案合计 | ≤96 字 |

- 三个字段**可全空**（纯视觉）
- **有副标题/卖点时必须有标题**；不为每张图强配标题
- **文案逐字冻结** —— 确认后下游不得新增口号、改写或润色

## 无文案模式

用户要求主图/详情图不新增文案时，跳过文案生成，方案中对应槽位标记**纯视觉**，保留产品原有文字。

## 套图方案策划

- **默认 4 张主图 + 6 张详情图**（用户可改）
- 每张图解决一个**不同的购买问题**，不重复
- 商品身份与视觉系统**强锁定**；场景、人物、道具、镜头尺度与构图**受控变化**

每槽必须声明七项：

| 字段 | 内容 |
|------|------|
| 用途 | 这张图解决什么购买问题 |
| 文案 | 标题/副标题/卖点（可全空） |
| 呈现角色 | 商品主体 / 场景 / 细节 / 对比 / 背书 |
| 真实性模式 | 实拍还原 / 情景示意 |
| 场景族 | 属于哪一类场景 |
| 镜头尺度 | 特写 / 中景 / 全景等 |
| 多样性档 | catalog_strict / adaptive / campaign_rich |

**多样性三档**：

| 档位 | 说明 |
|------|------|
| `catalog_strict` | 白底目录风，可单场景 |
| `adaptive` | **默认档** |
| `campaign_rich` | 广告投放级，场景最丰富 |

**情景示意**（模特实穿、手持、摆盘、空间摆放等）**不得**宣称精确合身、垂坠、材质或功效。

## 确认流程（强制）

1. **完整草稿一次产出**：文案 + 套图方案，写入 `outputs/02-marketing-copy.md` 与 `outputs/03-image-set-plan.md`
2. 在对话中**完整展示**（不是摘要、不是文件路径），请用户确认或修改
3. 用户修改后应用改动、重新展示再确认；确认后在文件中标注「**已确认**」及时间，之后不再改动

## 边界

- 不编造虚假宣传；信息不足就减少文字或使用纯视觉槽位
- 不把内部证据、设计理由、审核结论写进消费者文案
- 不修改用户已确认的文案，除非用户明确要求重新生成
