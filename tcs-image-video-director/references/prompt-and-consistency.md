# 提示词工程与跨镜一致性

决定"像不像、稳不稳"的两件事：提示词结构，和跨版本的一致性控制。

## 一、画幅 × 用途矩阵

| 用途 | 画幅 | 关键提示 |
|---|---|---|
| 社交海报 / 主视觉 KV | 16:9 或 1:1 | 留安全边距，文字区避开画面中心 |
| 商品白底图 / 电商主图 | 1:1 | 主体占画面 60–70%，背景纯净 |
| 短视频 / 竖版口播 | 9:16 | 主体居中偏上，预留标题与字幕条 |
| 故事分镜 / 多镜短片 | 16:9 | 统一焦距与影调 |
| 视频封面 / 缩略图 | 16:9 或 9:16 | 单核心事件，缩到信息流尺寸仍可读 |

只在所选模型声明画幅字段时传入。做多平台时按**最大平台尺寸先做，再裁各比例**，不要 16:9 硬裁成 16:10。

## 二、结构化提示词

**出图（文生图 / 图生图）**

```
[主体] + [动作/姿态] + [环境/场景] + [光线/时段] + [镜头/景别] + [风格/质感] + [负面：…]
```

**出片（文生视频 / 图生视频）** 在上式后补：

```
[运镜] + [时长/节奏] + [首帧状态 → 尾帧状态] + [音频意图]
```

**电影感八段式**（风格放靠后，让它"染色"场景而不是替换场景）：

```
[风格] + [主体] + [场景] + [光] + [构图] + [角度] + [焦点] + [色调] + [氛围]
```

**锁人脸写法**：`保持[图1]中人物的长相、[发型]、[服装]、[动作]，背景是[…]，[光线]，[氛围]`

## 三、负向词与质量增强

```
cluttered background, extra fingers, distorted face, deformed hands,
small unreadable text, watermark, busy patterns, low contrast, blurry
```

质量增强按需：`8K, sharp focus, cinematic, high saturation, volumetric lighting, film grain`。

不要堆矛盾词（"极简"配"繁复背景"），不要加与用户指定风格冲突的增强词。

## 四、跨镜一致性五法

1. **主体资产复用**：稳定的人物/商品建一次资产，后续直接引用，不每镜重述长相
2. **基准图参考**：定稿一张风格图作为后续 i2i 基准，只改弱点区域："保持其他不变，把[ ]改成[ ]"
3. **系列一次生成**：需要一组关联图时在同一会话内成组出，主体/色调/氛围更齐
4. **锁种子/参考帧**：模型支持时记录 seed 或参考帧作连续性基线；**不支持时不虚构"已锁定"**
5. **漂移必查**：首饰、Logo 位置、缝线、发缝、背景道具最先漂——定稿前逐个数一遍

一致性是"强但不保证"，迭代本身也计费，预算要留迭代量。

## 五、主体资产与动作资产必须分离

| | 控制什么 | 不能做什么 |
|---|---|---|
| 主体资产 | 脸、发型、体型、商品外形与包装 | 不控制动作；不能靠它跨镜改表演 |
| 动作资产 | 走位、姿态、表演幅度、机位关系 | 不能把源视频里的脸和服装一起迁入 |

规则：

- 多镜故事、系列角色、同商品多版本、反复同场景 → **主动查库复用**，先说"我会先复用已有角色和动作保持这几条一致"
- 单次临时图不需要复用 → 不强制建库
- 建库 ≠ 生成媒体：只要求建库时不得先跑去生图、生视频
- 创建成功要拿到**真实资产 ID**；上传成功、表单打开、任务受理都不等于入库成功
- 图片型主体与视频型主体不可互换；模型不支持主体时不塞主体参数
- 改标签/口味冲突时：不同包装不能共用一个主体后只改提示词里的名字

## 六、常见漂移与修法

| 现象 | 优先修法 |
|---|---|
| 脸/身份漂 | 换回主体资产引用，补正面参考，降低动作幅度 |
| 商品结构漂 | 换更清晰的包装参考，锁定轮廓与开口，局部重修 |
| 衣物部件丢失 | 降低动作幅度，先用关键帧把穿着构图定稳 |
| 风格漂成真人 | 强化媒介词（二维/黏土/毛绒），去掉写实光影词 |
| 建筑/场景变形 | 减少相机运动，先修基础图再动 |
| 文字变成乱码 | 停止要求模型出字，改后期叠加 |

## 七、验收时必看的高风险位

透明材质与反光、手指与握持、包带与包扣结构、液体折射、脚与地面的接触阴影、运动中段的衣纹跳变、画幅边缘截断。**先看静态关键帧，再看运动中段，最后听声音。**
