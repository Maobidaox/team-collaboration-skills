# 画幅、平台与出图组合

> 平台规则会变，规格以各平台后台最新要求为准；下表用于**出图前定画幅**，不要当合规依据。

## 一、画幅速查

| 用途 | 画幅 | 像素建议 | 注意 |
|---|---|---|---|
| 电商主图（白底） | 1:1 | ≥1000×1000 | 主体占 60–70%，四周留白，纯白底 |
| 详情页长图 | 3:4 或 2:3 | 宽 ≥1200 | 纵向分段，每段一个信息点 |
| A+ / 信息图 | 1:1 或 3:4 | 2000×2000 起 | 移动端优先，字要够大 |
| 小红书 | 3:4 | 1080×1440 | 信息流展示面积最大 |
| 抖音 / 快手 / Reels | 9:16 | 1080×1920 | 避底部按钮区与左下角时长标签 |
| 视频号 | ≈6:7 | 1080×1260 | 分享到朋友圈会裁 1:1，核心元素居中 |
| 淘宝/天猫主图视频封面 | 1:1 | 800×800 起 | 与主图同比例，视觉延续 |
| Amazon 主图 | 1:1 | ≥1000px（可放大） | 主图纯白底不加文字水印 |
| 杂志大片 / 海报 | 4:5 或 16:9 | 按投放位 | 单核心事件，留标题区 |

**多平台同一张图时：按最大尺寸先做，再裁各比例，不要反向拉伸。**

出组合时**一张一个 prompt，不要合并**——模型对单图单任务的执行力远高于多任务。

## 四、交付组合时的写法

```
【出图 Prompt 1/5 · 主图】
{...}

【出图 Prompt 2/5 · 细节微距】
{...}

...

【使用建议】
- 建议生成顺序：先出 01 主图定调，再拿它当参考图出其余 4 张，整体一致性最好
- 白底图一起上传，产品形态不会飘
- 13 尺寸图与 11 信息图的数字/文字必须后期核对
```

**先定一张锚图，再用它做参考图生成其余**——这是整套图保持一致的唯一可靠办法。
