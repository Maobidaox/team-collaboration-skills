# UI 设计系统与界面交付

设计系统优先、可访问性内建、交付可落地。**先有组件基础，再有页面；一致性靠 token 与模式，不靠逐页微调。**

## 核心立场

1. **设计系统优先** —— 先定基础组件与 token，再做单个页面；可复用模式防止设计债。
2. **可访问性内建（默认 WCAG AA）** —— 不是做完再补：对比度 4.5:1（正文）/ 3:1（大字与图形）、键盘可完整操作、语义化标签与 ARIA、可见焦点态。
3. **性能意识** —— 优化图片/图标/字体体积，CSS 写法考虑渲染成本，加载态与渐进增强是设计的一部分。
4. **意图性美学** —— 避开「一眼 AI」的通用审美（详见 `references/impeccable/SKILL.md` 的 AI Slop Test）：要么极大化、要么极简，关键是明确的选择而不是强度。

## 工作流（四步）

### Step 1：设计上下文（不可跳过）

动手前必须明确三件事，**不能靠读代码库推断**（代码只说明做了什么，不说明为谁做、该是什么感觉）：

- **目标受众** —— 谁用？在什么情境下用？
- **使用场景** —— 他们要完成什么任务？
- **品牌调性** —— 界面应该给人什么感觉（专业克制 / 活泼俏皮 / 奢华精致 / 工业实用…）？

收集顺序：① 指令中已有 Design Context 就直接采用 → ② 读项目根的 `.impeccable.md` → ③ 都没有则先走上下文收集流程（见 `references/impeccable/references/teach-impeccable.md`）。

同时确认技术约束：框架、是否需要暗色、性能预算、必须支持的断点与浏览器。

### Step 2：设计系统基础

产出 token 与基础组件：颜色（品牌/语义/中性）、字体阶梯、间距（4px 基准）、阴影层级、圆角与过渡。逐项模板见 `references/design-system-foundation.md`。

### Step 3：组件架构与视觉层级

- 基础组件：按钮、表单、卡片、导航、反馈（alert/toast/modal/tooltip）、数据展示
- 每个组件覆盖**五态**：default / hover / active / focus-visible / disabled，外加 loading / error / empty
- 明确动效与微交互（状态变化驱动，非装饰驱动）
- 响应式行为逐组件写清（不是「整体缩一缩」）

组件清单与状态矩阵见 `references/component-states.md`。

### Step 4：开发者交接与 QA

产出可量化的规格（尺寸、间距、色值、字号行高）、切图与多格式资源、使用规范的组件文档，以及设计 QA 验收流程。模板与检查清单见 `references/handoff-and-qa.md`。

## 硬规则

1. **对比度** —— 正文 ≥ 4.5:1，大字号（≥18.66px 粗体或 ≥24px）与图形元素 ≥ 3:1；**不能用纯黑 #000 配纯白 #fff**，中性色偏向品牌色。
2. **焦点可见** —— 所有可交互元素有 `:focus-visible` 样式，键盘 Tab 顺序符合视觉顺序，不移除 outline 而不给替代。
3. **触达区域** —— 移动端可点击元素 ≥ 44×44px，相邻可点区域留 ≥8px 间隔。
4. **不靠颜色单独传递信息** —— 状态（成功/警告/错误）必须同时有图标或文案，照顾色觉障碍用户。
5. **尊重减少动效** —— 包裹 `@media (prefers-reduced-motion: reduce)`，提供关闭入口。
6. **文本可缩放** —— 用 rem/相对单位，浏览器放大到 200% 不破版。
7. **禁用态要真的禁用** —— `disabled` 元素同时具备视觉弱化、`cursor: not-allowed`、`pointer-events: none`，不能只是变灰但仍可点。
8. **避免万物皆卡片** —— 卡片是分组手段不是默认容器；禁止卡片内套卡片。
9. **间距有节奏** —— 用间距 token（4/8/12/16/24/32/48/64）创造变化，不要所有元素等距排列。
10. **响应式优先容器查询** —— 组件自适应用 `@container`，布局切换才用 `@media`；移动端不得隐藏关键功能。

## 设计品味红线（AI Slop）

出现以下任一即为不合格，需重做：

- 字体选 Inter / Roboto / Arial / Open Sans 这类默认堆；把等宽字体当「技术感」
- 标题上方放大图标 + 圆角容器（万能英雄区模板）
- 紫蓝渐变 + 霓虹点缀 + 默认深色 + 发光效果
- 毛玻璃（backdrop-blur）滥用；圆角 + 通用阴影到处贴
- 所有按钮都是主按钮；居中一切；无意义装饰与火花线
- 弹性/回弹缓动做布局动画；动画化 `width/height/top/left` 等触发布局的属性

正确方向：独特的展示字体 + 精致的正文排版；`oklch()` / `color-mix()` / `light-dark()`；`clamp()` 流体尺寸；状态驱动的动效与 `ease-out-quart/expo` 指数缓动。

## 交付格式

按 `references/handoff-and-qa.md` 的模板输出：设计基础（颜色/字体/间距）→ 组件库（含状态）→ 响应式策略 → 可访问性声明 → 关键文件路径与实现代码。所有数值用具体数字（"4.5:1 对比度""16px 间距""8 点栅格"），不用"合适""协调"这类模糊表述。
