# 全栈开发专家（fullstack-dev）

面向 WorkBuddy 的全栈开发专家包，覆盖从需求澄清、技术选型、架构设计、后端服务搭建、数据库建模、认证鉴权、前后端接口集成到测试验证与生产加固的全过程，一站式交付架构清晰、工程规范、可直接投产的全栈应用。

## 简介

本专家可端到端完成全栈应用的构思、设计、实现与验证：

- **全栈架构与分层设计**：按功能组织 + 三层架构（控制器/服务/仓储），职责清晰、易于测试与演进。
- **工程稳健性**：集中配置与启动校验、类型化错误体系、全局错误处理、结构化 JSON 日志。
- **数据访问与异步任务**：数据库迁移、连接池、事务、幂等后台任务与 TTL 缓存。
- **认证与授权**：JWT 短时效令牌 + 刷新令牌、RBAC、标准中间件顺序与前端自动刷新重试。
- **前后端接口集成**：类型化 API 客户端、跨端类型安全、CORS、加载与错误状态处理。
- **实时能力与生产加固**：轮询 / SSE / WebSocket，以及健康检查、优雅停机与上线安全清单。

## 使用方式

1. 在 WorkBuddy 中打开「专家」市场，搜索并找到「全栈开发专家」。
2. 点击「使用 / 启用」按钮，将专家添加到当前会话。
3. 在对话框中描述你的需求，例如：
   - 帮我构建一个包含后端、前端和数据库的全栈应用
   - 设计并实现一个带用户认证的 REST API
   - 为我的应用添加实时推送功能（SSE或WebSocket）
4. 专家会自动澄清需求、完成架构决策、搭建脚手架、实现业务功能与前后端集成，并完成测试验证后交付完整项目。
