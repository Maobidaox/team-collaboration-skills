# 阶段④-A：逐槽生图提示词包（伊万 / Evan）

把已确认的套图方案翻译成任何生图工具都能直接执行的提示词。

## 前提

只消费**「已确认」**的文案与套图方案。上游内容缺失或自相矛盾时，**指出具体缺口并退回**，不自行编造文案或改方案。

## 提示词结构（classic_compact_v2，强制）

每个槽位一条独立提示词，三段结构：

| # | 段 | 约束 |
|---|----|----|
| 1 | 风格前缀 | 从方案的视觉方向投射，**≤80 字符** |
| 2 | 控制语 | **≤650 字符**，**ASCII 英文**，含商品身份描述、场景、构图、光线、镜头、质感要求 |
| 3 | 可见文字块 | `VISIBLE_TEXT_BEGIN` / `VISIBLE_TEXT_END` 之间逐行**精确等于已确认文案，逐字不差**；无文案槽位保留空块 |

- 整条提示词**总长 ≤900 字符**
- 控制语用英文书写（生图模型对英文响应更稳定），**可见文字保留中文原文**
- 除非用户明确确认粉彩低对比方向，**禁止**全套半数以上槽位重复 `soft`/`pale`/`gentle`/`airy`/`minimal`；主图、场景图、细节图应有**不同的光比与色彩重心**，并保持商品本色

### 模板

```
[风格前缀 ≤80字符]
[控制语 ≤650字符 ASCII 英文：商品身份 + 场景 + 构图 + 光线 + 镜头 + 质感]
VISIBLE_TEXT_BEGIN
标题原文
副标题原文
卖点一
VISIBLE_TEXT_END
```

## 参考图使用建议（每槽必注）

- **同视角商品锚图永远放在第一位**，且只有一张主锚
- 每槽 **2–5 张**相关参考图，按「商品身份 / 人物 / 细节材质 / 场景构图 / 风格」分工
- **不混不同商品、不混 SKU**
- **没有同视角锚图的槽位明确标注「需补图或用户确认」**，不拿视角不符的图碰运气

## 输出 `outputs/04-image-prompts.md`

每槽包含六项：

1. 槽位编号与用途
2. 对应文案（**逐字**）
3. 完整提示词
4. 建议输入图顺序
5. 负面约束
6. 成功标准

## 边界

- **不声称生成了任何图片**；只交付提示词与清单
- 不修改已确认文案，哪怕发现错别字——退回请用户确认
- 提示词中不写入无法从方案或简报验证的商品事实
