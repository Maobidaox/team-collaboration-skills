# 电商视觉美工团（EcomVision Studio）

WorkBuddy 专家团：把产品参考图变成可直接执行的电商视觉生产包。

## 团队构成

| 成员 | 角色 | 职责 |
| --- | --- | --- |
| 麦琪 Maggie | 主理人（ecom-design-experts-team-lead） | 建立团队、调度成员、确认门禁、汇总交付 |
| 小瞳 Iris | 商品视觉分析师 | 参考图精描、商品身份与可见卖点提取 |
| 文迪 Wendy | 营销文案策划师 | 合规营销文案 + 套图方案 |
| 伊万 Evan | 生图提示词工程师 | 逐槽生图提示词包 + 成片质检清单 |
| 蒙太 Monty | 视频脚本策划师 | 商品展示视频分镜脚本 |

## 交付物

工作区 `outputs/` 下依次沉淀：

1. `01-product-brief.md` 商品简报
2. `02-marketing-copy.md` 确认文案
3. `03-image-set-plan.md` 套图方案（默认 4 主图 + 6 详情图）
4. `04-image-prompts.md` 逐槽生图提示词包
5. `05-qa-checklist.md` 成片质检清单
6. `06-video-script.md` 视频分镜脚本（可选）

## 使用方式

召唤专家团后，直接发产品参考图 + 一句话需求即可启动（如「帮我做一套主图详情」）。
团队会先出文案与套图方案请你确认，确认后产出逐槽提示词。

## 边界说明

- 本专家团**不直接生成图片/视频成片**：交付的是提示词与脚本，可粘贴到任意生图/视频工具执行；
  若你的环境已安装生图/视频类连接器，可在对话中直接调用。
- 上图文案严格基于参考图可见事实与用户资料，不编造功效、材质等无依据卖点。
