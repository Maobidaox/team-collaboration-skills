# 成交驱动力与 Campaign Style Lock

> 解决两个最容易翻车的环节：**驱动力判断错了，后面全白做**；**Style Lock 没锁死，逐张生成必然漂移**。

## 1. 驱动力怎么判（别看品类，看卡点）

同样一类商品，卡点不同，主驱动力就不同。用「买家此刻那句话」反推：

| 买家心里那句话 | 驱动力 | 首图该先给什么 |
|---|---|---|
| 「这么便宜，能是好东西吗」 | 视觉/质感 | 材质特写、光影质感、包装档次 |
| 「这玩意儿到底管不管用」 | 痛点/效率 | 问题现场 → 使用动作 → 结果状态 |
| 「参数够不够，跟我家那个配不配」 | 理性/参数 | 关键参数 + 适配关系图 |
| 「敢不敢给孩子吃 / 敢不敢送人」 | 信任/证据 | 产地、工艺、检测、资质（真实可查） |
| 「它配不配我的生活」 | 情绪/身份 | 场景氛围、使用仪式、使用者形象 |

### 判断顺序

1. 先问：**如果没有这张图，买家最可能在哪一步走掉？** 答案就是主驱动力。
2. 再问：**哪一条证据最难被质疑？** 它决定辅驱动力（通常落在「信任」）。
3. 主驱动力的视觉必须占首图（Hero）的绝对主导，辅驱动力往后放。**不要在主图上做两个驱动力的平衡。**

### 常见误判

| 误判 | 后果 | 修正 |
|---|---|---|
| 高客单就以为是「情绪/身份」 | 买家真正卡在「值不值这个价」→ 应是信任/证据 | 看评价里被反复问的问题 |
| 3C 就以为是「理性/参数」 | 若外观同质化严重，卡点可能在外观质感 | 看竞品主图是否都是白底参数 |
| 食品就以为是「信任/证据」 | 零食冲动品真正的卡点是「好吃吗、什么味」→ 视觉/质感 | 看价格带与决策时长 |
| 把「痛点/效率」写成恐吓 | 制造焦虑但无解决方案，反而降低信任 | 问题场景只占 1/3，主体仍是解决方案 |

## 2. Feature → Advantage → Benefit → Evidence

| 层 | 是什么 | 写错的典型 |
|---|---|---|
| Feature | 客观属性 | 抄说明书原文（「采用 XX 工艺」） |
| Advantage | 这个属性带来什么不同 | 又写一遍参数（「XX 工艺更先进」） |
| **Benefit** | **买家能感知到的好处** | 空泛承诺（「更省心」「更专业」） |
| Evidence | 支撑它的事实 | 无来源的精确数字 |

**只保留 Top 3 购买理由**。第 4 条起删——买家的记忆位只有 3 个，第 4 条会稀释前 3 条。

检验方法：把 Benefit 读给一个没看过商品的人听，如果他问「凭什么」，说明 Evidence 没跟上；如果他问「所以呢」，说明 Benefit 还停在 Advantage。

## 3. Campaign Style Lock（九项必须写死）

一套图开做前先填完，后面每张图都对齐它。漏一项就等着漂移。

### 3.1 产品身份（最高优先级）

- Logo 形态、位置、比例
- 包装文字内容与语言（**不得翻译、不得改写、不得补字**）
- 主色（给具体色值或参照物，如「潘通 872C 金」）
- 规格/容量标识
- 结构特征（瓶型、罐型、开盖方式、封口）
- 材质观感（哑光/亮面/磨砂/金属/玻璃）

### 3.2 构图体系

- 主体占画面比例（如 55–65%）
- 视角（平视/俯视 45°/微俯/仰视）
- 留白位置与比例（文字区放哪）
- 视线流向（从左到右 / 中心放射 / 对角）
- 是否允许人物、手部、道具、水花/漂浮元素

### 3.3 色彩体系

主色 / 辅助色 / 强调色各一个，并写明**强调色只用于什么**（如「仅用于价格或数字」），防止逐张新增强调色。

背景色必须锁定：纯白（#FFFFFF）还是浅灰还是场景色。**纯白与浅灰不能混用在同一组图里**——这是最常见的低级漂移。

### 3.4 光影体系

选一种并写死：自然窗光 / 柔光棚拍（主光+反光板）/ 硬光（明确阴影方向）/ 侧逆轮廓光 / 顶部散射。

同时定：阴影软硬、是否有投影、投影方向、高光位置。**阴影方向在同一组图里反了，一眼就是拼的。**

### 3.5 字体与信息密度

- 标题字体族 + 字重（只用一个字重做标题，一个做正文）
- 中文/英文/数字是否用不同字体
- 数字必须比同层级文字大多少（建议 1.4–1.8 倍）
- 单张图文字总面积上限

### 3.6 背景与场景

纯底 / 渐变底 / 棚拍棚景 / 真实生活场景 / 品牌氛围场景。写明是否允许出现同类竞品、餐具、植物、织物等道具。

### 3.7 必须保留（Reference Fidelity）

从用户参考图里逐项列出**一个都不能变**的元素。默认包含：包装结构、Logo、包装文字、主色、规格标识、配件数量。

### 3.8 允许变化

明确写出来，否则执行者不敢动：场景、道具、镜头角度、光影方向、模特、背景色（若已允许）、构图裁切。

### 3.9 禁止项（Negative Constraints）

默认必带：包装变形 / Logo 改写或缺失 / 包装文字乱码 / 新增不存在的配件或赠品 / 规格数量变化 / 人物手指异常 / 文字糊成色块 / 风格跳变。

## 4. 参考图保真：三级优先级

用户上传产品图时，冲突按这个顺序裁决：

| 优先级 | 内容 | 冲突时 |
|---|---|---|
| **1** | 产品身份（Logo/包装文字/结构/颜色/规格） | 绝对不让步，只能改拍法 |
| **2** | 材质与真实观感 | 不让步（不能把塑料拍成金属） |
| **3** | 构图、光影、场景、道具 | 可自由调整 |

**判断口诀**：能被买家拿实物对照出来的，都不能变；只能被「感觉」到的，都可以变。

如果用户要求的效果与产品真实身份冲突（如要求把方形罐拍成圆形），**不要照做也不要沉默**——直接说明冲突点，给两个可选项：保真实身份换拍法，或确认用户是否要改产品。

## 5. 跨境本地化的七项检查

不做直译。至少过一遍：

- [ ] 该卖点在目标市场**是否被理解**（可能需要换一个购买理由）
- [ ] 单位是否本地化（g/oz、cm/in、ml/fl oz、℃/℉）
- [ ] 使用/食用/送礼场景是否符合当地习惯
- [ ] 依赖中文文化语境的表达是否已重写或解释
- [ ] 品牌名、产品名、产地名、品类名是否全站统一
- [ ] 合规边界是否按**目标市场**重新判断（不能把中国批准范围移植过去）
- [ ] 文字密度是否适配英文/其他语言的长度（英文通常比中文长 30–50%）

**最常被忽略的一条**：中文主图一行放 8 个字很舒服，翻成英文可能要 4 个单词，直接撑爆版面。定文案时就要按目标语言预留长度。
