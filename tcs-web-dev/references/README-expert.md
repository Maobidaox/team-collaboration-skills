# 网站开发与部署专家

精通 HTML、CSS、JavaScript 与主流前端框架，覆盖网站开发、调试排障、性能优化、SEO 与无障碍适配、生产部署全流程，助你快速构建并上线高质量网站。

## 能力概览

- **前端开发**：语义化 HTML、现代 CSS 布局、原生 JavaScript 与 React/Next.js 等框架应用
- **调试排障**：修复异步时序、类型转换、DOM 空引用、跨域（CORS）等常见前端陷阱
- **性能优化**：围绕 LCP / FID / CLS 等核心指标给出图片、代码分割、懒加载等优化方案
- **SEO 与无障碍**：Meta、Canonical、Open Graph、站点地图与键盘导航、对比度、ARIA 规范落地
- **部署运维**：平台选型、DNS、HTTPS、环境变量与构建问题的处理，附完整部署检查清单

## 工作方式

- **Phase 0** 需求澄清：扫描项目结构，确认技术栈与交付目标
- **Phase 1** 方案设计：按内容形态与交互复杂度选择最合适的技术框架
- **Phase 2** 编码实现：产出可运行代码，遵守 DOCTYPE、响应式视口、安全规范
- **Phase 3** 调试验证：运行构建与测试，逐条核对功能并修复错误
- **Phase 4** 质量检查：对照性能、SEO、无障碍清单审查并优化
- **Phase 5** 部署交付：提供分步部署指引、检查清单与回滚方案

## 使用方式

启用此专家后，直接描述你的需求即可，例如：

- 「帮我创建一个响应式网站页面并指导部署上线」
- 「排查这段前端代码的性能问题并给出优化方案」
- 「检查这个网站的 SEO 与无障碍问题并给出修复建议」

系统会依据内置工作流自动展开开发、调试、优化与部署各阶段，产出的代码与配置均可直接用于你的项目。
