# 工作台模块库（常见模块与集成方式）

设计工作台时，从下方挑选/组合模块，按业务场景裁剪。每个模块给出典型「解决什么」与「常见集成方式」。

## 一、通用基础模块
| 模块 | 解决什么 | 常见集成方式 |
|------|---------|-------------|
| 任务中心 | 待办、项目、进度统一管理 | 原生看板 / 对接项目管理工具 |
| 总览仪表盘 | 关键指标一屏可见、快速决策 | 数据源 API / 导出汇总 |
| 通知中心 | 异常、待办、审批集中提醒 | 邮件 / IM 机器人 / 站内信 |
| 知识库 | 文档、SOP、FAQ 集中检索 | 文档系统 / 搜索引擎 |
| 设置中心 | 权限、集成、自动化规则配置 | 原生配置 |

## 二、按场景的高频模块
### 销售/增长团队
- 线索池（CRM 接入）、商机看板、业绩排行、跟进提醒、报价生成。
- 集成：CRM API、表单、邮件/IM、数据看板。

### 培训运营
- 课程库、学员进度、培训日历、考试与证书、讲师排期、学习看板。
- 集成：LMS、报名表单、日历、证书系统。

### 项目管理
- 需求池、迭代看板、风险雷达、工时与成本、交付物库、周报自动生成。
- 集成：项目工具 API、工时表、文档、IM。

### 内容/创作
- 选题池、素材库、发布日历、多平台分发、数据回流。
- 集成：内容平台 API、云存储、分析后台。

### 客服/运营
- 工单台、知识库、SLA 监控、满意度看板、自动回复。
- 集成：工单系统、IM、满意度调查。

## 三、自动化触发类型（参考）
- **时间触发**：每日/每周定时（日报、周报、晨会材料）。
- **事件触发**：新表单/新工单/状态变更（建任务、通知、指派）。
- **条件触发**：指标越阈/逾期/异常（预警、升级、提醒）。
- **审批流**：提交→审批→执行（请假、采购、发布）。

## 四、集成方式梯度（自包含优先）
1. **原生/低代码**：平台内置模块，零/低开发，迁移成本低（首选）。
2. **连接器/Webhook**：官方或第三方连接器，配置即用。
3. **API 桥接**：自建轻量脚本/服务对接，可控但需维护。
4. **导出导入**：定时文件同步，最稳但实时性差（兜底）。

> 选型原则：在满足需求前提下，优先靠前的集成方式，降低锁定与维护成本。
