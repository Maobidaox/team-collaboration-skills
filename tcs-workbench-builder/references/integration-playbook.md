# 集成与数据流设计（Step 4）

## 一、集成方式梯度（优先靠前）

| 梯度 | 方式 | 适用场景 | 成本 | 风险 |
|------|------|---------|------|------|
| 1 | **原生/低代码** | 平台内置模块能满足 | 零/低开发 | 迁移成本低，**首选** |
| 2 | **连接器 / Webhook** | 官方或第三方连接器覆盖 | 配置即用 | 受连接器能力限制 |
| 3 | **API 桥接** | 需要定制逻辑或连接器不支持 | 自建脚本/服务，需维护 | 可控但有人力成本 |
| 4 | **导出导入** | 无 API、无连接器 | 定时文件同步 | 实时性差，**兜底用** |

**决策原则**：在满足需求前提下选最靠前的。不要因为「API 更灵活」就上第 3 档——每上一个梯度，维护成本翻倍。

## 二、数据流三段式描述

每条数据流写清：**源 → 工作台 → 目标**，并标注频率与方向。

```markdown
| 数据流 | 源 | 方向 | 频率 | 集成方式 | 备注 |
|--------|----|------|------|---------|------|
| 客户线索 | CRM | → 工作台（读） | 每 15 分钟 | 连接器 | 只读，不回写 |
| 跟进状态 | 工作台 | → CRM（写） | 实时（用户操作时） | API | 需幂等键，冲突以 CRM 为准 |
| 日报汇总 | 工作台 | → 企业微信群 | 每日 9:00 | Webhook | 失败重试 3 次后告警 |
```

**读 vs 写要分开标注**：读失败可以降级显示旧数据，写失败必须明确告知用户并保留重试入口。

## 三、写回源系统的四条硬约束

写入比读取风险高一个量级，涉及写回时必须写明：

1. **幂等** —— 同一操作重复执行结果一致（用业务唯一键，不要用时间戳）
2. **冲突策略** —— 源系统数据已被他人修改时怎么办（以源为准 / 以工作台为准 / 提示人工决策）**必须选一个**，不能含糊
3. **失败可见** —— 写失败要让用户看得见，不能静默吞掉
4. **可回滚** —— 至少保留操作日志，能查到谁在什么时候把什么改成了什么

## 四、选型对比模板（推荐 + 备选 + 理由 + 风险）

```markdown
| 维度 | 推荐：XXX | 备选：YYY |
|------|----------|----------|
| 满足需求 | 全部 P0 | 全部 P0 |
| 部署成本 | 半天 | 2 天 |
| 年成本 | ¥0（已有账号） | ¥6,000 |
| 迁移成本 | 数据可导出为标准格式 | 私有格式，导出受限 |
| 锁定风险 | 低 | 中高 |
| 选它的理由 | 团队已在用，零学习成本，数据可迁出 | — |
| 不选它的理由 | — | 成本高且数据导出受限，团队规模未定，暂不锁定 |
```

**写「不选它的理由」比写「选它的理由」更重要** —— 它逼你真的比较过，而不是选了第一个想到的。

## 五、待确认清单（必须显式列出）

以下信息未知时，标注「待确认」并在交付物末尾集中列出，**不要默认它能行**：

| 类型 | 例 |
|------|----|
| 凭证与权限 | 「CRM 管理员授权 —— 待确认（需找张 XX 申请）」 |
| 接口能力 | 「CRM 是否提供线索状态更新接口 —— 待确认（需查文档）」 |
| 字段可得性 | 「客户手机号能否导出 —— 待确认（涉敏，可能需要脱敏）」 |
| 数据量 | 「历史线索约多少条 —— 待确认（影响是否需分页/增量同步）」 |
| 网络与环境 | 「工作台是否可访问内网 CRM —— 待确认」 |

## 六、敏感数据处理

方案中涉及敏感数据时，至少覆盖三点：

- **脱敏展示** —— 手机号 `138****5678`、身份证仅后 4 位；列表页默认不展示完整敏感字段
- **最小权限** —— 按角色授予字段级/行级权限（销售只看自己的客户，组长看全组）
- **操作审计** —— 谁在什么时候查看/导出了什么，留痕可查；批量导出需二次确认

## 七、常见集成失败点

| 失败点 | 预防 |
|--------|------|
| 以为有 API，实际只有导出 | 动手前先验证接口存在与权限可用 |
| 同步频率定得过高 | 先每日跑通，再按需提频；实时同步要论证业务必要性 |
| 只考虑成功路径 | 每条数据流都要写「源不可用怎么办」（降级显示 / 告警 / 用上次缓存） |
| 字段映射靠猜 | 列字段映射表，逐字段确认类型与空值处理 |
| 把敏感数据同步到第三方平台 | 先确认数据合规要求，必要时只同步脱敏后的聚合值 |
