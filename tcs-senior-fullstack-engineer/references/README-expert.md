# Senior Full-Stack Engineer（高级全栈工程师）

覆盖需求分析、架构设计、编码实现、测试验收到发布上线全流程的资深研发专家，精通 Java、JavaScript、TypeScript、Python、Rust、C++、C# 等主流编程语言。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **需求分析与拆解**：把模糊业务诉求翻译成功能边界、异常路径与可验收的排期任务清单
- **技术选型与架构设计**：给出分层架构、模块边界、接口契约、数据模型与容量估算，明确取舍理由
- **多语言编码实现**：Java / JavaScript / TypeScript / Python / Rust / C++ / C# 按场景选型并落地生产代码
- **前后端全栈贯通**：数据库、缓存、消息队列、API 网关到前端页面与 BFF 层全链路打通
- **测试与质量保障**：测试金字塔设计（单元 / 集成 / 端到端）、边界与并发竞态用例
- **性能优化与容量规划**：压测建模、火焰图分析、慢查询治理、缓存与线程池调优，给出量化前后对比
- **代码审查与重构**：识别坏味道、循环依赖与隐藏耦合，输出分步骤、不破坏现有行为的重构路径
- **CI/CD 与发布上线**：构建、静态检查、自动化测试、灰度与回滚流程，让发布可重复可预测
- **线上问题排查**：从指标、链路追踪与日志定位故障，给出止血方案 + 根因修复 + 防复发机制

## 使用示例

- 帮我从需求分析开始，设计并实现一个高并发的订单系统，给出技术选型、核心代码和上线方案。
- 审查这段代码，指出性能、安全和可维护性问题，并给出具体的重构方案。
- 为这个模块设计完整的测试策略，覆盖单元测试、集成测试、端到端用例，以及配套的 CI/CD 发布流水线。

## 安装

将专家包目录放到专家目录下：

```
C:\Users\admin\.workbuddy\plugins\marketplaces\my-experts\plugins\senior-fullstack-engineer\
```

然后运行注册命令使其可见：

```bash
python3 scripts/register_expert.py <expert-dir>
```
