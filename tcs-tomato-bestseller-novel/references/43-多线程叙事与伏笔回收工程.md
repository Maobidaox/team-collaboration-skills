# 43 · 多线程叙事与伏笔回收工程（v2 新增）

> **口径日期：2026-09-11** ｜ 长篇崩盘的三大元凶：**线头太多收不回、伏笔埋了忘、B 线喧宾夺主**。本节给出一套可执行的线程管理工程。

## 一、长篇叙事的三条线（标准配置）

```
A 线 · 主线（主角目标）        —— 占篇幅 60%
B 线 · 副线（情感/成长/势力）  —— 占篇幅 25%
C 线 · 悬念线（大伏笔/真相）   —— 占篇幅 15%（但决定"追读到完结"）
```

**铁律**：**A 线永远不能让位**。B 线服务于人设厚度，C 线服务于长线期待。

## 二、伏笔工程四步法

### Step 1 · 埋（隐蔽）

| 埋法 | 说明 | 例子 |
|---|---|---|
| **道具埋** | 一件不起眼的东西 | 母亲留下的旧怀表 |
| **台词埋** | 一句被忽略的话 | "你左手为什么永远戴着戒指？" |
| **行为埋** | 一个反常举动 | 他从不在雨天出门 |
| **背景埋** | 一句环境描写 | 墙上挂着一张烧掉一半的合影 |

### Step 2 · 养（强化）

**每 20–30 章轻点一次**（读者会记住，但不会立刻想通）。
⚠️ **超过 50 章不点 → 读者忘了 → 回收时无感**。

### Step 3 · 收（回收）

| 回收方式 | 效果 |
|---|---|
| **直收** | 直接揭晓（适合中等伏笔） |
| **反转收** | 揭晓时改变含义（高价值） |
| **连锁收** | 一次收 2–3 个（高潮章节用） |

### Step 4 · 兑现（让读者爽）

**回收时必须给情绪回报**——"原来如此！"+"所以他才会……"→ 读者产生"我早该想到"的快感。

## 四、多线程并行技法（三条线怎么交错）

### 技法 1 · 主线带副线
```
第 10 章：主角打脸反派（A 线）
        → 同时也是女主对他改观的契机（B 线）
```

### 技法 2 · 悬念线做章末钩子
```
第 25 章末：主角发现怀表内侧的刻字（C 线埋点）
        → 强钩子，驱动追读
```

### 技法 3 · 三线交汇高潮
```
每 50–80 章安排一次"三线交汇"：
A 线打boos + B 线关系质变 + C 线真相揭晓
= 全书最强高潮
```

## 五、线程失控的五大信号（预警）

| 信号 | 说明 | 修法 |
|---|---|---|
| **线头 > 5 条** | 读者记不住 | 合并或砍掉 |
| **B 线篇幅 > A 线** | 主线停滞 | 把 B 线并入 A 线事件 |
| **连续 30 章无 C 线** | 长线期待消失 | 插一个 C 线小提示 |
| **伏笔超 50 章未提** | 读者已忘 | 立即轻点一次 |
| **支线人物抢戏** | 主角边缘化 | 支线事件必须服务于主角目标 |

## 六、三大"防崩"纪律

1. **新开线头前，先关旧线头**——**"开一关一"原则**；
2. **每卷必须有 1 个"主线的确定性推进"**（读者要看得见进度）；
3. **伏笔回收率 ≥80%**——埋了不还，读者会觉得被耍。
