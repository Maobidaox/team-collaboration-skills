# 16 · 分卷分章大纲与逐章细纲模板（口径：2026-09）

> 大纲决定你能不能**写到 100 万字不崩**。
> 配套脚本：`outline_builder.py`

---

## 一、三层大纲体系

```
第一层 · 总纲（1 页）：核心冲突 + 主角目标 + 终局 + 3 个记忆点
第二层 · 分卷（3–10 卷）：每卷一个「小终局」+ 一个新格局
第三层 · 逐章细纲（前 30 章必须写全）：每章事件 + 转折 + 章末钩子
```

**铁律**：**前 30 章细纲必须在开书前写完**。后面可以边走边写，但前 30 章是数据决定期，不能即兴。

---

## 二、分卷结构（起承转合）

| 卷 | 功能 | 字数参考 | 卷末必须发生 |
|---|---|---|---|
| 第 1 卷 | 立局 | 15–25 万 | 主角获得立足点，格局跃迁一次 |
| 第 2 卷 | 扩张 | 20–30 万 | 势力/身份升级，出现更强的对手 |
| 第 3 卷 | 对抗 | 25–35 万 | 与主要敌对势力正面碰撞 |
| 第 4 卷 | 真相 | 20–30 万 | 世界观真相部分揭晓 |
| 第 5 卷 | 终局 | 15–25 万 | 核心矛盾解决，收束支线 |

> 短篇 / 中篇按比例压缩，但**「卷末必须发生什么」这条不能省**。

---

## 三、逐章细纲模板（前 30 章用）

```
第 X 章 | 拟定章名
─────────────
【本章目标】主角要达成什么（一句话）
【核心事件】发生了什么（2–3 句）
【转折点】哪一刻局面变化
【爽点】本/章爽点类型（对照 12 号文件）
【章末钩子】用了哪一式（对照 13 号文件）
【字数目标】2000–2400
【伏笔】本章埋了什么 / 回收了什么
─────────────
```

## 四、四大台账（防止长篇崩盘）

| 台账 | 记录内容 | 更新频率 |
|---|---|---|
| **设定台账** | 世界观规则、力量等级、专有名词 | 每次新增设定 |
| **人物台账** | 出场人物、关系、当前状态、口头禅 | 每次人物变化 |
| **伏笔台账** | 埋下的伏笔 + 预计回收章 | 每章检查 |
| **时间线台账** | 事件发生的先后顺序与时间跨度 | 每章更新 |

> 详细方法见 18 号文件。

## 五、更新与存稿规划

| 阶段 | 日更建议 | 存稿建议 |
|---|---|---|
| 开书前 | —— | 存稿 ≥ 3 万字（10 章） |
| 首月 | 4000–6000 字 | 保持 ≥ 5 天日更量 |
| 冲榜期 | 6000–10000 字 | 保持 ≥ 7 天日更量 |
| 稳定期 | 4000–6000 字 | 保持 ≥ 5 天日更量 |

**用 `serial_scheduler.py` 自动生成排期表与存稿预警。**

## 六、大纲自检清单

- [ ] 总纲能一页写完吗？（写不完说明没想清）
- [ ] 前 30 章每章都有章末钩子吗？
- [ ] 每卷卷末都有格局跃迁吗？
- [ ] 伏笔台账里的每一项都有回收计划吗？
- [ ] 对手阶梯排好了吗（越往后越强）？
- [ ] 主线是否单一清晰（支线 ≤ 2 条）？

## 七、工具支持

```bash
# 生成分卷与逐章细纲
python scripts/outline_builder.py --title "书名" --track 都市脑洞 --chapters 30

# 只生成某一卷
python scripts/outline_builder.py --volume 2 --chapters 40

# 伏笔体检
python scripts/outline_builder.py --check-foreshadow 大纲.md
```
