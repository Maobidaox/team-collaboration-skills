# 21 · 追读率 / 完读率数据诊断与救书 SOP（口径：2026-09）

> **数据不好先别慌，先归因。** 归对了，一次就能救回来。

---

## 一、六数诊断法

| 数据 | 低说明什么 | 首要抓手 |
|---|---|---|
| **点击率低** | 书名/封面/简介不行 | 09 号文件包装工程 |
| **首章完读低** | 前 200 字劝退 | 10 号文件前 200 字公式 |
| **三章留存低** | 黄金三章节奏不对 | 10 / 11 号文件 |
| **追读率低** | 章末钩子弱 / 人设无黏性 | 13 / 15 号文件 |
| **阅读时长短** | 章节太水或太短 | 12 号文件密度标准 |
| **收藏转化低** | 主角目标不清晰 | 16 号文件大纲三章自检 |

---

## 二、掉量归因树（从症状到根因）

```
阅读量下降
├─ 是不是断更了？ ─────── 是 → 立刻恢复日更 + 补存稿
├─ 是不是首章完读掉了？ ─ 是 → 检查前 200 字是否被改过
├─ 是不是追读率降了？ ── 是 → 抽样最近 5 章，看章末钩子质量
├─ 是不是新书分流？ ─── 是 → 差异化标签是否够清晰
├─ 是不是章节字数缩水？  是 → 恢复 2000+ 字
└─ 是不是内容被判低质？  是 → 对照 04 号文件自查
```

---

## 三、30 天救书作战表

| 天数 | 动作 | 目标 |
|---|---|---|
| D1–D3 | 全量数据复盘 + 定位根因 | 确定唯一主因 |
| D4–D7 | 改造前 10 章的章末钩子 | 追读率回升 |
| D8–D14 | 安排一次中型高光（打脸/逆转） | 阅读量台阶回升 |
| D15–D21 | 优化书名/封面/简介（若 CTR 低） | 点击率回升 |
| D22–D30 | 稳定日更 + 每 3 章一个爽点 | 数据进入平台中上游 |

---

## 四、何时该「切书」（放弃判定）

出现以下任意两条，建议考虑开新书而非硬救：

1. 追读率连续 4 周低于赛道均值 30% 以上；
2. 已完成一次完整救书（30 天）仍无回升；
3. 题材本身已过风口（见 06 号文件月度雷达）；
4. 核心设定存在无法修补的结构性矛盾；
5. 作者本人对该题材失去动力（写作质量会随之崩）。

> **理性切书不是失败，是把时间投到更有胜率的地方。**
