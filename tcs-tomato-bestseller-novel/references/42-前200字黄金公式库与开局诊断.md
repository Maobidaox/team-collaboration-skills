# 42 · 前 200 字黄金公式库与开局诊断（v2 新增）

> **口径日期：2026-09-11** ｜ 2026 年算法**只看前 3 章完读率**（脑洞类 ≥15%、传统类 ≥10%）。**前 200 字决定读者走还是留。**

## 一、前 200 字的四个任务（缺一不可）

```
前 50 字  → 出事（冲突/异常/倒计时）
50–120 字 → 定人（主角是谁、什么处境）
120–160 字 → 立钩（悬念/反差/金手指迹象）
160–200 字 → 起势（读者想知道"然后呢"）
```

**铁律**：**第一章前 300 字内必须出冲突，第一章内必须亮金手指，拒绝慢热铺垫。**

## 二、八大前 200 字公式（可直接套）

### 公式 1 · 倒计时开局
```
【异常事件 + 倒计时 + 主角反应】
例：「距离死亡还有 3 分钟。——而我，连自己是谁都不知道。」
```

### 公式 2 · 身份反差开局
```
【低微身份 + 被羞辱 + 内里藏着的东西】
例：「'一个送外卖的也配站在这儿？' 保安的话音未落，我把手里的文件递了过去。」
```

### 公式 3 · 规则宣读开局（规则怪谈专用）
```
【规则条目 + 违反后果 + 主角处境】
例：「第一条：不要回头看。第二条：如果听到有人叫你，答应的那一刻，你就不是你了。」
```

### 公式 4 · 结果前置开局（先给爽点）
```
【先给高潮结果 + 倒叙引发好奇】
例：「当所有人跪在地上叫我大人的时候，没有人记得，三天前我还被扔在乱葬岗。」
```

### 公式 5 · 认错人开局（现言/豪门）
```
【误认 + 尴尬 + 反转伏笔】
例：「我一把抱住眼前的人哭得上气不接下气，直到他清冷地开口：'小姐，你认错人了。'」
```

### 公式 6 · 系统提示开局（系统流/脑洞）
```
【机械提示音 + 荒谬任务 + 主角反应】
例：「【叮！检测到宿主即将死亡，是否绑定'死后重生'系统？倒计时 10 秒，默认同意。】」
```

### 公式 7 · 危机倒逼开局（末世/生存）
```
【灾难降临 + 生存倒计时 + 唯一选择】
例：「城市的天空在三分钟前变成了血红色。手机上的短信只有六个字：囤货，锁门，别信人。」
```

### 公式 8 · 反常日常开局（都市脑洞）
```
【正常场景 + 一个不对的细节 + 主角发现】
例：「今天的煎饼摊老板还是老样子，直到我看见，他找给我的零钱上，印着 2077 年的日期。」
```

## 三、开局诊断六查（写完必查）

| # | 检查项 | 不合格表现 | 修法 |
|---|---|---|---|
| 1 | **前 50 字是否出事** | 还在写天气/环境 | 把冲突提到第一句 |
| 2 | **主角是否已出场** | 前 200 字没见过主角 | 第一句让人物行动 |
| 3 | **是否有具体细节** | 全是抽象概括 | 换成可感知的动作/物件 |
| 4 | **是否埋了钩子** | 读完没有疑问 | 加一个悬念或反常 |
| 5 | **是否有信息过载** | 一次性塞世界观 | 拆到后续章节 |
| 6 | **是否 AI 腔** | 句式工整、形容词堆砌 | 过 ai_flavor_remover.py |

## 四、五类"自杀式开局"（禁区）

| 类型 | 表现 | 为什么致命 |
|---|---|---|
| **天气开局** | "清晨的阳光洒在……" | 无冲突、无信息 |
| **回忆开局** | "十年前的那个夏天……" | 读者不关心过去的你 |
| **设定倾泻** | 一上来解释等级/势力 | 信息过载 |
| **对话无主** | 两个人说话，不说是谁 | 读者懵 |
| **主角缺席** | 前 500 字别人在演 | 无代入感 |

## 五、开局强度评分（10 分制）

| 维度 | 10 分 | 6 分以下 |
|---|---|---|
| 冲突前置 | 前 50 字出事 | 100 字后仍无异常 |
| 代入感 | 第一句主角在行动 | 主角是旁观者 |
| 钩子强度 | 读完只想点下一章 | 读完没有疑问 |
| 语言质感 | 有具体细节 | 空泛形容词 |
| 信息密度 | 每 50 字一个新信息 | 200 字说了一件事 |

**工具**：`python hook_density.py --file 稿件.md --mode 开局`（前 200 字强度扫描）

## 六、改造示例（从"劝退"到"抓人"）

**改造前**：
> 清晨，阳光透过窗帘洒进房间。林轩睁开眼睛，看了看时间，已经到了上班的时候。他是一名普通的程序员，过着平凡的生活。

**改造后**：
> 林轩是在自己被通缉的新闻里醒过来的。
> 电视上，主持人念着他的名字，说他是"编号 749 失踪案"的唯一嫌疑人。
> 而他，连昨天发生了什么，都不记得。

⇒ **区别**：出事了、主角在场、有悬念、有具体细节。
