# 07 · 男频爆款赛道公式库（口径：2026-09）

> 本文件给出男频主流赛道的**可复用公式**：钩子 → 节拍 → 爽点 → 对手 → 翻车点。
> 配套脚本：`bestseller_fingerprint.py --track <赛道>`

---

## 一、都市脑洞 / 都市异能

- **核心钩子**：现代都市 + 一个不讲道理的设定。
- **节拍**：设定亮相 → 规则试探 → 首次打脸 → 能力升级 → 势力扩张 → 世界真相。
- **爽点配方**：信息差 + 打脸 + 扮猪吃虎。
- **对手设计**：由「傲慢小人物」递进到「体系性对手」。
- **翻车点**：设定过重压节奏；前 3 章不亮牌必死。

## 二、高武 / 玄幻 / 修仙

- **核心钩子**：可量化的力量体系 + 越级挑战。
- **节拍**：体系亮相 → 受辱 → 觉醒/奇遇 → 越级打脸 → 宗门大战 → 登顶。
- **爽点配方**：越级 + 打脸 + 资源掠夺。
- **翻车点**：体系膨胀失控 → 中期战力崩坏。

## 三、规则怪谈

- **核心钩子**：诡异规则 + 逻辑破局 + 生死倒计时。
- **节拍**：规则登场 → 违规死亡 → 找漏洞 → 首次破局 → 规则升级 → 源头真相。
- **爽点配方**：解谜 + 智商碾压 + 幸存者抱团。
- **翻车点**：规则自相矛盾，被读者抓逻辑漏洞。

## 四、无限流

- **核心钩子**：轮回副本 + 能力继承 + 幕后悬念。
- **节拍**：入局 → 副本规则 → 团队碰撞 → 通关 → 结算 → 幕后初现。
- **爽点配方**：通关 + 生存碾压 + 羁绊。
- **翻车点**：副本同质化、队友工具人化。

## 五、历史穿越

- **核心钩子**：现代知识 × 古代困局。
- **节拍**：入局危机 → 知识破局 → 站稳 → 势力上升 → 庙堂博弈 → 定鼎。
- **爽点配方**：智斗 + 阶级跃迁 + 众望所归。
- **翻车点**：史实硬伤、节奏拖沓。

## 六、科幻末世

- **核心钩子**：末日危机 + 物资/能力稀缺 + 生存秩序重建。
- **节拍**：末日降临 → 生存 → 建立据点 → 势力冲突 → 真相 → 新秩序。
- **爽点配方**：生存碾压 + 资源掌控 + 秩序重建。
- **翻车点**：设定堆砌、人性描写脸谱化。

## 七、系统流（通用增强件）

> 系统不是赛道，是**增强件**，可挂在任意赛道上。

- **作用**：把「成长」可视化、把「目标」明确化、把「爽点」节奏化。
- **用法铁律**：系统只给「方向」，不给「答案」——否则主角变成工具人。
- **翻车点**：系统播报占篇幅过大（超过正文 15% 即显廉价）。

## 八、电竞 / 直播整活

- **核心钩子**：强对抗 + 观众反应 + 逆袭感。
- **节拍**：亮相 → 被质疑 → 首胜 → 对抗升级 → 大舞台 → 封神。
- **爽点配方**：碾压 + 打脸 + 群体见证。
- **翻车点**：专业细节失真、比赛描写流水账。

## 九、男频通用公式（跨赛道复用）

```

第一章必做三件事：
  ① 亮出「主角的异常」（300 字内）
  ② 给一次「小胜」或「强钩子」
  ③ 埋一个「他想知道答案」的问题

每 3 章一个小高潮：打脸 / 升级 / 获得
每 10 章一个大高潮：势力级胜利 / 身份揭晓
每 30 章一次格局跃迁：换地图 / 换对手层级
```
