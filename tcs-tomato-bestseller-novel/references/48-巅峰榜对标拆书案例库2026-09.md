## 二、拆书四纪律（不做无意义拆书）

1. **拆结构不抄文字**——只提炼可复用的结构，绝不复制原文；
2. **拆前三十章为主**——决定生死的关键在开篇；
3. **每本只提炼 3 条可迁移规律**——贪多嚼不烂；
4. **必须落到"我这本书怎么用"**——否则拆书 = 看小说。

## 三、六种常见爆款结构模式

| 模式 | 结构特征 | 适配赛道 |
|---|---|---|
| **A · 逆袭打脸型** | 低起点 → 受辱 → 得金手指 → 打脸 → 更高层受辱 → 循环 | 赘婿、都市高武 |
| **B · 副本闯关型** | 进入副本 → 破规则 → 成长 → 下一副本 | 无限流、规则怪谈 |
| **C · 身份揭秘型** | 隐藏身份 → 被误解 → 逐步掉马 → 全员震惊 | 豪门马甲、真假千金 |
| **D · 经营养成型** | 一穷二白 → 逐步建设 → 壮大 → 对外扩张 | 西幻领主、种田、都市修真 |
| **E · 复仇寻真型** | 遭遇变故 → 追查真相 → 层层揭开 → 终极对决 | 悬疑、复仇流 |
| **F · 苟道蛰伏型** | 低调苟着 → 暗中变强 → 一朝爆发 | 长生流、苟道流 |

## 四、拆书报告标准模板（可直接复用）

```markdown
# 《书名》拆书报告

## 一、基本信息
- 赛道 / 体量 / 当前数据 / 作者等级

## 二、七维爆款基因
1. 核心钩子（一句话卖点）
2. 首章必胜动作（第一章做了什么）
3. 结构节拍（几章一个爽点/高潮）
4. 爽点配方（用了哪几型爽点）
5. 钩子配置（章末钩子类型分布）
6. 人设张力（主角内核反差）
7. 金句调性（语言风格特征）

## 三、前 30 章结构图解
（逐章一句话 + 标注爽点/钩子）

## 四、三条可迁移规律
1. ______（可用到我的书：______）
2. ______
3. ______

## 五、不可迁移的部分
（避免踩雷的独创性内容）

## 六、移植方案
（我的题材 ______ → 借用结构 ______ → 具体调整 ______）
```

## 六、拆书的一句话心法

**「我不是在学它写什么，我是在学它为什么让人停不下来。」**

⇒ 拆的是**节奏、结构、情绪设计**；不是**情节、文字、设定**。
