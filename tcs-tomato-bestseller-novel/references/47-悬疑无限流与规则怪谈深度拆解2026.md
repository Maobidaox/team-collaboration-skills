## 二、三大子类型拆解

### 2.1 无限流（副本闯关）

```
核心公式：主角进入副本 → 破解规则 → 生存/获胜 → 得到成长 → 进入下一副本
```

| 要素 | 设计要点 |
|---|---|
| **副本规则** | 规则要"看似合理、细思极恐" |
| **智斗** | 主角靠推理而非战力破局 |
| **死亡压力** | 违规即死（提升紧张感） |
| **轮回设定** | 死亡可重来（十日轮回） |
| **伏笔链** | 每个副本藏一条主线线索 |

### 2.2 规则怪谈（2026 最热子类）

```
核心公式：规则条文 + 违规后果 + 主角用常识/科学破局
```

**规则设计三原则**：
1. **规则要反常识**（"不要回头""半夜不要照镜子"）；
2. **规则要自洽**（为什么会有这条规则）；
3. **破局要合理**（主角靠逻辑/知识，不是靠运气）。

**爆款范例方向**：
- 《我每天能固化一个物理定律》——用牛顿定律教诡异做人；
- 《规则怪谈：我能看见隐藏提示》——金手指是"看见规则漏洞"。

### 2.3 民俗灵异（中式恐怖）

```
核心公式：民俗元素（出马/风水/狐仙/邪物典当铺）+ 都市/乡土背景 + 灵异事件
```

| 要素 | 说明 |
|---|---|
| **民俗考据** | 有真实民俗依据，增强可信度 |
| **氛围感** | 靠细节营造压迫感（不靠血腥） |
| **单元结构** | 一个事件一章/几章，天然适配短篇 |
| **短剧/漫剧适配** | 视觉奇观强，改编价值高 |

## 三、开篇模板（悬疑专用）

```
第 1 章：规则/异常直接抛出 → 主角身处其中
第 2 章：第一次违规代价（或目睹他人违规）→ 建立危机感
第 3 章：主角发现第一个破局线索 → 小反转
```

**范例**：
> 「桌上的纸条写着三条规则：
> 一、不要给任何人开门。
> 二、如果听到敲门声，请数到十。
> 三、如果数到十之后门还在响——
> 那就不是人了。」

## 四、本赛道的三大优势（为什么值得写）

| 优势 | 说明 |

| **改编友好** | 单元剧结构 + 视觉奇观 → 短剧/漫剧适配度高 |
| **短篇适配** | 民俗单元剧适合新人试水（3–5 万字即可） |

## 五、三大风险（必须告知用户）

1. **智斗门槛高**：逻辑不严密 → 读者骂"降智"；
2. **恐怖分寸**：涉及迷信邪教致害内容**违规**（须写"智斗破局"而非"崇拜"）；
3. **同质化严重**：规则怪谈已大量涌入，需要**强差异化设定**。

## 六、合规边界（本赛道特别注意）

| 可写 | 不可写 |
|---|---|
| ✅ 民俗文化、民间传说 | ❌ 宣扬迷信、邪教 |
| ✅ 恐怖氛围、心理惊悚 | ❌ 详细描写犯罪手法 |
| ✅ 智斗破局、科学解释 | ❌ 迷信致害的"正面示范" |

**技法替换**：**写恐怖 → 写心理压迫与未知感；写暴力 → 写后果与旁观者反应。**

## 七、写作 checklist

```
□ 前 300 字抛出规则/异常
□ 第一章建立"违规=代价"的危机感
□ 每章末尾一个悬念钩子
□ 破局靠逻辑/知识（不是运气）
□ 规则自洽（能解释为什么）
□ 单元结构清晰（一个事件一个闭环）
□ 主线伏笔藏在副本里
```
