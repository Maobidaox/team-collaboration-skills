# 41 · AI 辅助创作合规边界与协作范式（2026-09）

> **口径日期：2026-09-11** ｜ 不是"用不用 AI"，而是"**怎么用 AI 才既高效又安全**"。本节给出可直接执行的协作范式。

## 一、灰色地带的三个真问题

行业普遍认同：
- **合规**：查资料、校对错别字（辅助）
- **违规**：AI 直接生成完整正文（代写）
- **灰色**：AI 写大纲算不算？AI 润色算不算？（**中间地带巨大**）

**自保原则**：**越靠近"核心创作"（人设/冲突/情节/情绪），越要人工主导。**

## 二、AI 协作的"三环模型"

```
┌─────────────────────────────────────────┐
│  外环 · 完全可用（合规辅助）              │
│  · 资料搜集  · 错别字校对  · 词句润色     │
│  · 起角色名  · 想书名备选  · 整理素材     │
├─────────────────────────────────────────┤
│  中环 · 谨慎使用（必须深度改写 ≥60%）      │
│  · 大纲框架  · 章节骨架  · 场景初稿       │
│  · 对话初稿  · 环境描写                   │
├─────────────────────────────────────────┤
│  内环 · 严禁 AI（必须人工原创）            │
│  · 核心人设  · 主线冲突  · 关键情节转折    │
│  · 情绪爆点  · 名场面设计  · 金句         │
└─────────────────────────────────────────┘
```

## 三、五大协作场景的标准动作

### 场景 1 · 选题阶段（AI 辅助分析）

```
人工：定方向（我想写都市脑洞）
AI  ：列出该赛道近期爆款特征 + 读者偏好
人工：决策（结合 topic_score.py 打分）
```

### 场景 2 · 大纲阶段（AI 出框架，人工重写内核）

```
AI  ：生成"三卷结构 + 前 30 章细纲"骨架
人工：重写核心冲突、人设、每个转折的动机
并  ：用 outline_builder.py 校验伏笔回收
```

### 场景 3 · 正文阶段（AI 只做"局部零件"）

```
✅ 可用：把"人物情绪"扩展成一段对话初稿 → 人工改写 ≥60%
❌ 禁止：让 AI 直接生成整章正文
✅ 可用：AI 提供 3 种打脸方式 → 人工选一种自己写
```

### 场景 4 · 润色阶段（合规且高效）

```
AI  ：识别 AI 味指纹、给出改写建议
人工：执行改写（换句式、加细节、调节奏）
并  ：ai_flavor_remover.py --suggest 复检
```

### 场景 5 · 质检阶段（AI 做检测，不做出题）

```
quality_selfcheck.py 打分 → 若 <95 分 → 生成优化提示词 → 人工重写
```

## 四、反检测的"人工改写率"标准

| 内容类型 | 建议人工改写率 | 说明 |
|---|---|---|
| 环境/过渡描写 | ≥40% | 允许 AI 初稿 |
| 对话 | ≥60% | 必须有角色个体腔调 |
| 情节推进 | **≥80%** | 核心创作 |
| 情绪爆点/名场面 | **100%** | 必须手写 |

## 五、六个"高危用法"（立即停止）

| # | 高危用法 | 后果 |
|---|---|---|
| 1 | AI 直接生成整章正文后小改 | 判定 AI 代写 |
| 2 | 用 AI"拆爆款骨架 + 填血肉" | 判定洗稿 |
| 3 | 批量多开、AI 量产 | 封号 |
| 4 | 用同一套模板生成多本书开头 | 被识别为批量 |
| 5 | 细纲直接用 AI 拆书产出 | 与他人的产出雷同 |
| 6 | 让 AI 写完再"换同义词" | 检测模型可识别 |

## 六、协作出品质量对比（为什么要人工主导）

| 环节 | 纯 AI 产出 | AI 辅助 + 人工主导 |
|---|---|---|
| 句式参差 | ❌ 均匀 | ✅ 有跳跃 |
| 情绪曲线 | ❌ 平淡 | ✅ 有起伏 |
| 人物腔调 | ❌ 一个声音 | ✅ 各有口癖 |
| 逻辑自洽 | ❌ 常矛盾 | ✅ 台账校验 |
| 追读率 | ❌ 低 | ✅ 高 |
| 合规风险 | 🔴 高 | 🟢 低 |

## 七、工具链（AI 协作专用）

```bash
# AI 味检测与改写建议
python ai_flavor_remover.py --file 稿件.md --suggest

# 文风一致性检查（防 AI 段落"跑调"）
python ai_flavor_remover.py --file 稿件.md --check-consistency

# 节奏诊断（含 AI 味维度）
python rhythm_analyzer.py --file 稿件.md --curve

# 质检 + 自动优化提示词
python quality_selfcheck.py --file 稿件.md --prompt-out 优化提示词.md
```
