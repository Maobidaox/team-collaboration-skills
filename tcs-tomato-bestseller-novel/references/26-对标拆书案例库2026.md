## 二、常见爆款结构模式（抽象化）

### 模式 A · 「绝境 → 反转 → 碾压」

```
节拍：绝境(2章) → 觉醒/获得(1章) → 首次碾压(2章) → 对手升级 → 二次碾压
爽点：打脸 + 越级 + 群体见证
钩子：强敌断为主
适合：复仇、玄幻、都市脑洞
```

### 模式 B · 「规则 → 死亡 → 破局」

```
节拍：规则降临(1章) → 违规死亡(1章) → 找漏洞(2章) → 首次破局(2章) → 规则升级
爽点：智斗 + 幸存 + 反杀
钩子：问答断、倒计时断
适合：规则怪谈、无限流、悬疑
```

### 模式 C · 「误会 → 真相 → 追妻」

```
节拍：误会起(3章) → 对立加深(5章) → 真相半露(3章) → 反转(4章) → 双向救赎
爽点：虐 + 反转 + 身份 + 被爱
钩子：反转断、背叛断
适合：豪门虐恋、古言
```

### 模式 D · 「日常 → 糖点 → 并肩」

```
节拍：相遇(2章) → 心动(2章) → 小冲突(2章) → 告白(3章) → 并肩(持续)
爽点：糖点 + 被偏爱 + 小打脸
钩子：情绪断、承诺断
适合：甜宠现言、穿书
```

### 模式 E · 「家困 → 破局 → 起飞」

```
节拍：家庭危机(2章) → 手艺破局(3章) → 家业起步(5章) → 打脸极品(3章) → 时代机遇
爽点：生活流 + 打脸 + 阶级跃迁
钩子：信息断、承诺断
适合：年代种田、现实题材
```

## 三、拆书的四条纪律

1. **拆结构，抄语言 = 侵权**。结构（节拍、爽点类型、钩子类型）是通用方法论，语言是独创表达。
2. **不记录原文**：拆书笔记里不出现原作连续两句以上的原文。
3. **不照搬专有名词**：设定名、地名、组织名全部重写。
4. **拆完必须产出「移植方案」**，否则拆书等于白拆。
