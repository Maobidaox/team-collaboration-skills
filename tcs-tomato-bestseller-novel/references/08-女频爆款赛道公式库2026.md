# 08 · 女频爆款赛道公式库（口径：2026-09）

> 女频的核心不是「设定」，而是**情绪**。所有公式都服务于一个目标：
> **让读者在每一章获得明确的情绪回报（心动 / 心疼 / 痛快 / 被爱）。**

---

## 一、豪门虐恋

- **核心钩子**：强强拉扯 + 误会/背叛 + 追妻火葬场。
- **节拍**：虐点起 → 误会对立 → 真相半露 → 追妻反转 → 双向救赎 → 圆满。
- **爽点配方**：虐爽交替 + 身份反转 + 打脸白月光。
- **翻车点**：虐而无脑、女主降智（掉追读的头号杀手）。

## 二、甜宠现言

- **核心钩子**：高糖日常 + 双向奔赴 + 轻冲突。
- **节拍**：相遇 → 心动 → 小冲突 → 告白 → 并肩 → 圆满。
- **爽点配方**：糖点 + 宠溺 + 小打脸。
- **铁律**：每章至少 1 个糖点；冲突不过夜。
- **翻车点**：寡淡无冲突、糖点重复。

## 三、古言宅斗 / 宫廷权谋

- **核心钩子**：深宅权谋 + 步步反击 + 身份反转。
- **节拍**：入局被害 → 自证反击 → 掌权 → 朝堂牵连 → 身份揭晓 → 登顶。
- **爽点配方**：反击 + 智商碾压 + 身份逆袭。
- **铁律**：建立「对手阶梯表」，每 8–10 章换一个更强的对手。
- **翻车点**：套路陈旧、反派降智。

## 四、穿书 / 快穿

- **核心钩子**：穿越/穿书 + 已知剧情 + 反套路改写。
- **节拍**：穿书亮相 → 改命 → 原女主对抗 → 世界规则 → 真相反转 → 收官。
- **爽点配方**：碾压原剧情 + 打脸原女主 + 反向养成。
- **铁律**：必须写清「哪三处剧情会偏离」。
- **翻车点**：过度依赖原作、原创性不足。

## 五、年代种田

- **核心钩子**：物资匮乏年代 + 现代经验 + 家庭逆袭。
- **节拍**：危机立 → 手艺破局 → 家业起飞 → 乡邻打脸 → 时代机遇 → 家国。
- **爽点配方**：生活流 + 打脸极品亲戚 + 阶级跃迁。
- **铁律**：每 5 章解决一件「家事难题」，形成成就清单。
- **翻车点**：流水账、细节失真。

## 六、修仙女强

- **核心钩子**：女频视角修仙 + 逆天机缘 + 打脸升级。
- **节拍**：起点谷底 → 机缘觉醒 → 打脸同门 → 宗门立威 → 飞升 → 登顶。
- **爽点配方**：升级 + 打脸 + 情缘拉扯。
- **铁律**：机缘节奏表先行，每 12 章一次质变；男主不做挂件。
- **翻车点**：男主喧宾夺主、升级通胀。

## 七、复仇爽文

- **核心钩子**：血仇开局 + 步步复仇 + 打脸清单。
- **节拍**：血仇立 → 隐忍蓄力 → 首次复仇 → 清单推进 → 幕后黑手 → 清算。
- **爽点配方**：复仇 + 打脸清单 + 身份反转。
- **铁律**：建立「仇恨清单表」，每完成一项给一次大爽点。
- **翻车点**：复仇无终点、情绪透支。

## 八、萌宝团宠 / 星际言情 / 灵气复苏（速记）

| 赛道 | 钩子 | 铁律 | 翻车点 |
|---|---|---|---|
| 萌宝团宠 | 天才萌宝 + 身份悬念 | 萌宝每章至少 1 个高光 | 萌宝工具化 |
| 星际言情 | 强女主 + 星战格局 | 格局服务感情 | 设定压感情线 |
| 灵气复苏 | 时代变革 + 女主觉醒 | 个人成长与时代并行 | 设定说明过多 |

## 九、女频通用公式

```

情绪回报节奏（每章必须有）：
  心动 / 心疼 / 痛快 / 被爱 —— 至少命中一种

情绪爆发节奏：
  3 章一小爆（一次情绪高峰）
  10 章一大爆（一次命运转折）
  30 章一次格局跃迁（身份 / 地位 / 关系质变）

女主铁律：
  可以受伤，不可以降智；
  可以心软，不可以没底线；
  可以被误会，不可以自证无能。
```
