# 23 · 短篇赛道与短剧改编变现（口径：2026-09）

> 短篇是**低成本的试水场**，短剧改编是**高回报的第二曲线**。
> 两者共用同一套「强冲突 + 强人设」能力。

---

## 一、番茄短篇四类形态

| 类型 | 字数 | 核心 | 变现路径 |
|---|---|---|---|
| **情感故事** | 1–3 万 | 情绪浓度 | 打赏 + 改编 |
| **悬疑反转** | 1–3 万 | 结尾反转 | 阅读量 + 改编 |
| **脑洞爽文** | 1–3 万 | 设定新奇 | 阅读量 |
| **现实题材** | 1–5 万 | 真实共鸣 | 阅读量 + 活动奖 |

---

## 二、短篇黄金结构（五拍）

```
【第 1 拍】开局即冲突（前 200 字）
【第 2 拍】矛盾升级（第 1/3 处）
【第 3 拍】第一次反转（第 1/2 处）
【第 4 拍】高潮爆发（第 4/5 处）
【第 5 拍】结尾反转 / 情绪落点（最后 200 字）
```

**短篇铁律**：**没有一句废话**。每个字都要服务于「推进」或「情绪」。
**短篇比长篇难写**，因为它没有「慢慢铺」的空间。

---

## 三、短篇 → 长篇的孵化判断

写完短篇后，用这三条判断能否扩容：

1. **有可扩展的核心设定吗？**（能不能撑起 100 万字）
2. **有可延续的对手阶梯吗？**（短篇的对手够不够长）
3. **数据验证过吗？**（短篇的完读率与互动是很好的试水数据）

三条都过 → 可以扩成长篇；反之，短篇本身作为独立作品交付。

---

## 四、短剧改编（第二曲线）

### 改编方的选品偏好（行业共性）

| 偏好 | 说明 |
|---|---|
| **强冲突开局** | 前 3 分钟必须有爆点（对应小说前 3 章） |
| **强人设反差** | 主角身份反转、扮猪吃虎 |
| **单线清晰** | 主线明确，支线不杂 |
| **可拍摄性** | 场景可控、角色数量可控 |
| **情绪浓度** | 爽/虐/甜要极致，不要温吞 |

### 自荐改编的写法

```
【作品定位】一句话说明题材与爽点（≤30 字）
【核心冲突】三句话讲清主线矛盾
【人设亮点】主角 1 个 + 对手 1 个，各一句反差描述
【可拍性说明】主要场景（≤5 个）+ 主要角色数（≤10 个）
【数据成绩】阅读量 / 追读率 / 榜单成绩
```

## 五、IP 衍生注意事项

- **版权归属**：签约条款里要看清「改编权」的授权范围（见 25 号文件）；
- **原创性**：衍生作品必须基于自己的原创内容，不得使用他人作品元素；
- **授权边界**：未签约前不要对外承诺改编授权。

---

## 六、本章速查卡

- **短篇是试水场**：用最低成本验证「题材 + 人设 + 钩子」是否有效。
- **改编看三点**：强冲突、强人设、可拍摄。
- **改编权在合同里**，签约前务必看清授权范围。
