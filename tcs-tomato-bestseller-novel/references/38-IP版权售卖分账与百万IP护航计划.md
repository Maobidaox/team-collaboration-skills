# 38 · IP 版权售卖、分账与百万 IP 护航计划（2026-09）

> **口径日期：2026-09-11** ｜ 对头部作者，**版权收入可能超过听读分成**。本节讲清楚"作者能从 IP 里拿到什么、怎么拿"。

## 二、百万 IP 护航计划作战（重点）

### 2.1 奖励逻辑

- 申请【IP 保底金】需**同时满足对应档位的全部申请条件**；
- 平台会**综合评估**申请作品的**内容创新性、版权改编潜力**；
- 评估通过 → 获对应档位【IP 保底金】解锁资格。

### 2.2 新增的"友好档位"

**3 万元/人档位**：**不设作者历史版权收入门槛**，作品同时满足基础条件和质量要求即可申请。
⇒ **新人首次有了低门槛的 IP 变现入口**（注：该档位不享受活动保障金奖励）。

### 2.3 申请前的四个自查

| 自查项 | 标准 |
|---|---|
| 是否为番茄签约作品 | ✅ 必须 |
| 是否有历史版权收入门槛 | 3 万档：无；其他档位：有 |
| 内容创新性 | 有差异化设定/视角（非套路复刻） |
| 改编潜力 | 场景可视、单元剧结构、名场面密度 |

## 三、版权收入的四种形态

| 形态 | 说明 | 结算方式 |
|---|---|---|
| **授权金** | 一次性授权费 | 一次性 |
| **分账** | 按改编作品收益分成 | 按周期 |
| **保底 + 分成** | 保底金 + 超出部分分成 | 混合 |
| **全版权买断** | 一次性买断 | 一次性（⚠️ 慎签） |

## 四、签约必查的六个版权字段（避坑）

| # | 字段 | 要点 |
|---|---|---|
| 1 | **改编权范围** | 短剧/长剧/动漫/有声/出版，**逐项确认** |
| 2 | **分账比例** | 明确阶梯与结算周期 |
| 3 | **授权期限** | 是"永久"还是"X 年"，**永久买断要慎重** |
| 4 | **再授权** | 平台能否转授权第三方 |
| 5 | **保底金额** | 是否可抵扣 |
| 6 | **署名权** | 是否保留原著署名 |

⚠️ **作品页出现"短剧/网剧/漫剧原著"角标，只提示读者预期**，**收益、授权和档期仍要回到合同字段核对**。

## 五、"IP 潜力"最高的三类作品

| 类型 | 为什么 | 代表方向 |
|---|---|---|
| **强设定脑洞** | 设定即卖点，视觉冲击强 | 规则怪谈、异能、都市高武 |
| **强情绪关系** | 情感张力大，改编可塑性强 | 恶毒女配、豪门马甲、重生虐渣 |
| **强单元结构** | 天然适配短剧分集 | 悬疑单元剧、刑侦反转、乡土短篇 |

## 六、标准回答话术（被问"我能拿到多少版权费"）

> 「版权收入取决于**改编形式、授权范围、分账比例和谈判结果**，个体差异极大，**没有任何平台会承诺固定数字**。可以确定的是三条路径：① 短剧专项计划——单书最高 60 万改编版权奖励；② 爆款之源奖——现象级短剧原著单部最高 300 万；③ 百万 IP 护航计划——单人最高 200 万版权保底。**具体以番茄官方活动页当日规则与正式合同为准，重大事项请咨询专业人士。**」
